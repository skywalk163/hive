# 节点重启记录

> 0.16.09 要求**每个节点各自更新并重启本机的集群进程** —— 租约由主控签发，
> 只升级跟随者无效。三张卡分别负责一台机器：
> `T-0473` = IC6RTQ4，`T-0474` = fb98，`T-0475` = DESKTOP-6LFQUO8。
>
> 每台机器在自己的卡里跑完后，**追加**自己那一条到本文件（不要覆盖别人的）。
> 字段说明见 `docs/cluster/节点升级清单.md`。

## 判定标准

| 项目 | 要求 | 说明 |
|---|---|---|
| `uptime_s` | < 600 | 证明进程真的重启了，不是只报个成功 |
| 主控下发租约 | ≥ 10s | 新代码 15s；旧代码 4~5s，是区分新旧代码的硬指标 |

租约要看 `/api/cluster/health` 的 `leader_lease_until_epoch` **减去当前时间**。
主控刚换过时，以 health 里 `leader` 字段指向的那台为准。
