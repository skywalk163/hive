## 一、为什么做（成本结构，来自 R127/R129 盘点）

| 成本源 | 占比 |
|---|---|
| stdlib 函数名双轨/三轨（`读取` vs `读取文件`） | ~40% |
| lambda / with 缺失 | ~20% |
| 字典三套写法 | ~10% |
| 教学体 vs 工程体关键字分歧 | ~10% |
| 汉字 token 效率 | ~20% 以下 |

**约 60% 的 retry 不是「模型不会写」，而是「同一语义有多种合法写法」的选择负担**
（`docs/分层语法设计_v4.0.md` §1.1–1.2 自己就列了 8 类等价写法）。

所以本轮不是给模型喂更多变体，而是把语言变成**可判定、可归一、可局部修改**：
> 单一权威形态 + 宽容接受 + 强制归一 + 结构化诊断
