# 「清单说有、跑起来没有」的假绿（L-261，2026-11-07 复测仍红）

## 一、实测证据（light HEAD `8567a6588`）

```light
设 s 为 集合创建([1,2,2,3])
打印 转字符串(s)
```
→ **rc=1**，`错误: 名称错误 / name '集合创建' is not defined`。
而 `src/linter/builtins.py` 里 `集合创建` 出现在 **3 处（行 20 / 51 / 127）** —— linter 认为它是内置，
编译期不报未定义名，错误一路留到运行期。

```light
设 d 为 {"a":1}
字典设置默认值(d, "b", 5)
打印 转字符串(d)
```
→ **rc=1**，同样 NameError；但 `src/linter/builtins.py` 里**这个名字 0 处**，`stdlib/builtins.py` 里也是 0 处。
即「缺陷账写的两个假名」现状并不相同：`集合创建` 是清单假绿，`字典设置默认值` 是压根没实现。
先现场核清每个名字的真身，再决定补实现还是清登记，**不要照抄 10/30 的旧结论**。

现存门禁 `tests/unit/test_文档内置名存在性.py`（基线 **13 passed / 4.6s**）只查**文档里**的名字，
不查 **linter 清单里**的名字 —— 清单这侧一直是裸奔。
