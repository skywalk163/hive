## 背景

现在的派发是人肉搬运：看板看卡 → 记在脑子里 → 切到 agent APP → 手打 prompt 让 agent 领任务。
手打有三类稳定损耗：任务号抄错、契约漏讲、工具名说错。

本卡是「派发流水线」第一层（L1）的**纯逻辑内核**：把一张任务卡渲染成一段可以直接粘进
chat 的标准化派发指令。**本卡不碰 `hive.py`**（CLI 接线在 T-0188），只产出可被 CLI、
看板、脚本共用的无副作用函数。

## 要做什么

新建 `dispatch_prompt.py`（与 `conflict.py` 同级，纯标准库，不 import `hive.py`），提供：

```python
def extract_task_summary(card: dict, body: str, *, max_chars: int = 200) -> str
def build_dispatch_contract(card: dict, body: str) -> dict[str, list[str]]
def render_dispatch_prompt(card: dict, *, agent: str | None = None,
                           output_format: str = "markdown", body: str = "") -> str
def render_dispatch_payload(card: dict, *, agent: str | None = None,
                            body: str = "") -> dict
```

### 1. 输出格式（`output_format="markdown"`，逐字固定）

```text
请领取任务 T-0184。
任务摘要：<从任务卡标题 + body 的「背景」首段压缩，超长截断并加 …>
执行契约：
- 允许修改路径：<card.paths，空则写「（验收卡，不改代码）」>
- 预期输出：<card.verify 的逐条命令；空则写「见任务卡完成标准」>
- 失败策略：<timeout_minutes> 分钟内未完成即放弃；失败时把卡住的位置写进 .hive/summary.md 并回 hive_submit，不要硬凑
- 禁止行为：<body 里「不要做什么 / 红线」小节的条目；缺失时用三条默认：只改 paths 内文件 / 不动其它任务卡与 agents 配置 / 不写入任何 token 或密钥>
领取方式：调用 MCP 工具 hive_claim，参数 task_id=T-0184
完成后调用 hive_submit 提交。
```

- 指定 `agent` 时，在「领取方式」后追加一行：`领取身份：<agent>`（供 manual 模式核对是谁接的卡）。
- 文本必须是**纯文本语义**：不含 ANSI 转义、不含 markdown 表格、单行不超过 200 字符，
  行尾用 `\n`（Windows `clip` 能正确接收）。
- 同一输入必须逐字符一致（确定性，不依赖时间/随机/环境）。

### 2. `output_format="json"` / `render_dispatch_payload`

返回可直接 json.dumps 的 dict：

```json
{"task_id": "T-0184", "agent": null, "summary": "...",
 "contract": {"allowed_paths": [], "expected_output": [], "failure_policy": [],
              "forbidden": []},
 "claim_tool": {"name": "hive_claim", "arguments": {"task_id": "T-0184"}},
 "submit_tool": "hive_submit", "text": "<与 markdown 完全一致的正文>"}
```

非法 `output_format` 抛 `ValueError`。

### 3. 摘要与契约提取规则

- `extract_task_summary`：优先取 `card["title"]`；body 里若有 `## 背景` 小节，取该小节第一段
  拼在后面，总长不超过 `max_chars`，超长用 `…` 结尾（按字符截断，不能切坏 UTF-8）。
- `build_dispatch_contract`：从 `card["paths"]`、`card["verify"]`、`card["timeout_minutes"]`、
  body 的 `## 不要做什么` / `## 红线` 小节抽取；小节条目按 `- ` / `1. ` 开头识别；
  缺失一律回退到上文默认值，**任何字段缺失都不许抛异常**。

- 不读 git、不读文件系统、不发网络请求：模块只接受入参。读 body 由调用方完成（`render_dispatch_prompt(..., body=...)`）。
- 不加 CLI 参数、不引入第三方依赖、不写 `print`。
- 不动既有测试与 `conflict.py`。
