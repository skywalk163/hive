现在要用 hive 必须先 clone 整个仓（485 文件）。目标：`pipx install hive-cli` 后直接有 `hive` 命令。

要点：
  - 保持「git 即队列」语义不变，只是把 CLI 变成可安装的；
  - 入口点 `hive = hive:hive_cli_main`（现有 main 需要拆一层）；
  - 包内必须包含 init 时要拷贝的模块（hive_*.py / mcp_*.py / conflict.py 等），否则 init 会缺文件。

判据：空环境 pipx 装完 `hive doctor` 能跑。
