## 背景

L1 的最后一步是「看板点一下 → 切到 APP → 粘贴 → 回车」。T-0188 已提供 CLI 与
`status --json` 的 `stage` / `board` 字段。本卡把这两个能力搬到 Web 看板上：
**一个复制按钮，一列 dispatched 状态**。

看板保持**只读**语义：按钮只复制文本、不领卡、不改状态；标记已推送仍走
`hive dispatch-mark`（人或脚本调用）。

## 要做什么

### 1. `dashboard/serve.py` 新增只读接口

```text
GET /api/dispatch-prompt?task=T-0184&agent=trae-win[&format=markdown|json]
```

- 实现方式：`sys.path` 已含 `HIVE_ROOT`，直接 `import dispatch_prompt` 渲染，
  任务卡用 `parse_card(HIVE_ROOT/"tasks"/f"{tid}.md")` 读（**不要** shell 出去调 CLI）；
- 任务号必须匹配 `^T-\d{4}$`，否则 400；文件不存在 404；
- 沿用现有 `AGENT_NAME_RE` 校验 `agent`；
- 响应 `Content-Type: application/json; charset=utf-8`，body `{"task": tid, "format": ..., "text": ...}`；
- 失败时返回 JSON `{"error": "..."}`，不允许 500 裸栈。

### 2. `dashboard/app.js` + `index.html` + `style.css`

- 每张卡加一个「复制派发指令」按钮：`fetch` 上面的接口 → `navigator.clipboard.writeText`；
  失败回退到隐藏 `<textarea>` + `document.execCommand("copy")`（HTTP 非安全上下文下必走回退）；
  复制成功后按钮文字变「已复制」2 秒再复原，且**不刷新整页**；
- 列表/详情里显示 `stage` 徽标（`pending` / `dispatched` / `claimed` / `running` / `done` / `blocked`），
  `dispatched` 卡额外显示 `dispatched_to`（来源兼容 `card.dispatched_to` 与 `card.stage`）；
- 表头显示 `board` 摘要（`待分配 N / 已推送 M / 在跑 K`），字段缺失时静默降级为旧看板（不报错、不显示 undefined）；
- `style.css` 为徽标与按钮加样式，**不改动既有配色与布局变量**。

### 3. `dashboard/sample-status.json`

- 补一张 `dispatched` 卡与一张 `pending` 卡，字段用真实形态（`stage`、`dispatched_to`、`board`），
  让 `serve.py --status sample-status.json` 起来就能看到效果。

### 4. `tests/test_dashboard_dispatch_ui.py`

不启浏览器、不启真服务（CI 无 GUI），做三层断言：

1. **接口层**：用 `http.server` 在临时端口起 `serve.py`（`subprocess` 或直接 import 后线程起），
   `GET /api/dispatch-prompt?task=T-0184` 返回 200 且 `text` 含 `hive_claim`；
   非法任务号 → 400；不存在 → 404；`&format=json` → text 是 JSON 字符串；
2. **静态层**：`app.js` 含 `navigator.clipboard` 与 `execCommand("copy")` 两条路径、
   含 `api/dispatch-prompt`、含 `stage` 徽标渲染；
3. **降级层**：样例 JSON 缺 `board` / 缺 `stage` 时，JS 里对应取值都有兜底（断言源码含 `|| ` 兜底或函数默认值）。

## 不要做什么

- 不在看板上做写操作（不领卡、不改状态、不发 dispatch 请求）。
- 不修改 `hive.py` / `mcp_server.py` / `dispatch_prompt.py` / `dispatch_tracking.py`。
- 不在 `serve.py` 里 `subprocess` 调 `hive.py`（会引入 git 网络等待，拖死 HTTP 线程）。
- 不改已有的静态白名单与目录穿越防护；新增路由必须显式判断，不用通配。
