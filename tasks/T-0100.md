## 背景

hive 仓在 Gitea 上至今没有 CI：改动全靠人工 `python3 -m pytest tests` 自检，回归没人兜。
按最新决定「先开发 hive 自己，别的仓不碰」，CI 是第一块基石。

## 目标

新增 `.gitea/workflows/ci.yml`（push main + pull_request 触发，runs-on: `freebsd`，复用现有 fb5 runner，**不要**新增 label、不要改 act_runner.conf）：

1. checkout（用本地 actions/checkout，别回落 github.com）；
2. 起依赖：`python -m pip install pytest pytest-xdist`（本仓测试不需要 pytest-timeout；
   失败可回退 `--index-url https://pypi.org/simple`）；
3. `python -m pytest tests -q --tb=short`（几十秒级，**首次全绿即算过**，不搞基线对比）；
4. `bash -n scripts/*.sh`；
5. `python -m py_compile hive.py dashboard/serve.py`（serve.py 在 dashboard/ 下）；
6. `python -m json.tool agents/*.json >/dev/null`（顺带校验 agent 配置）；
7. `timeout-minutes: 30`（超时即红）。

另外把 `CI_REPOS=skywalk/hive ./scripts/ci-check.sh` 能读到最新 run 写进产出说明。

## 红线

- **不得改动 light / lighting / deepseek-harness 的任何内容**；ci-check 默认只盯 `skywalk/hive`。
- 不改 fb5 上的 runner 配置；不加 label。
- 测试要快：整仓 pytest 应该在 1 分钟内。

## 验收

`git show --stat HEAD` 含 `.gitea/workflows/ci.yml`；verify 全过；README 或手册提一句 CI。
