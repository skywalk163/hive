# 打了 v1.0.0 的 tag，但没有 LICENSE

## 现状（实测）

```
$ cd lightplugin
$ ls LICENSE
# 不存在

$ git tag
v0.1.0  v0.3.0  v0.4.0-rc1  v0.4.0-rc2  v1.0.0

$ ls .github/workflows
# 不存在

$ ls pyproject.toml setup.py
# 都不存在

$ git remote -v
origin  http://192.168.1.5:3000/skywalk/lightplugin   # 只有 gitea
```

但 README 说：

> 本目录是**独立 git 仓**（不是 monorepo 子仓），分支 `main`，三个远端同步：
> | gitea | http://192.168.1.5:3000/skywalk/lightplugin.git |
> | github | https://github.com/skywalk163/lightplugin.git |

**「三个远端」实际只有 1 个。** 我验过 `github.com/skywalk163/lightplugin` 是可达的
（HEAD = `42ab632`），只是本地没配 remote。

## 这个仓是什么

`lightplugin` 是用光明语言复刻 dsh 插件的仓，README 说：

> **当前状态：74/74 插件复刻完成**（24 个前置 + 第 7/8/9 批各 12 个 + 第 11 批 14 个），
> 74 个测试文件全绿，全程未改一行 `light-merge/src/`
> **154 个工具、工具名冲突 0 组、统一挂载 154/154、端到端冒烟 5/5**

规模不小，且它是 `lightharness` 的插件供应方（`lightharness/运行.py` 里有
`LIGHTPLUGIN` 环境变量和「插件生产接线根路径」的逻辑）。

`_smoke/` 目录已有 5 个冒烟脚本（`冒烟A_基础.light` 等），但没有统一的 `smoke.sh` 入口。

## 目标

### 1) 补 LICENSE（MIT）

```bash
cd /home/skywalk/dswork/lightplugin
cp ../light/LICENSE LICENSE
```

### 2) 补统一的 `smoke.sh`

`_smoke/` 有 5 个脚本，但没有一键跑全部的入口。写：

```bash
#!/usr/bin/env bash
# lightplugin 冒烟：跑 _smoke/ 下全部脚本，任一失败即红。
# 完整插件测试在 插件/ 下（74 个），见 README。
set -uo pipefail
cd "$(dirname "$0")"

fail=0
for f in _smoke/*.light; do
  [ -e "$f" ] || continue
  printf '%-40s ' "$(basename "$f")"
  if python3 运行.py "$f" >/tmp/_lp_smoke.log 2>&1; then
    echo "OK"
  else
    echo "FAIL"
    tail -5 /tmp/_lp_smoke.log
    fail=1
  fi
done
exit $fail
```

⚠️ **先确认 `运行.py` 的实际调用方式**（我看到的路径是 `lightplugin/运行.py`，
但参数形式以它的 docstring 为准）。另外 `_smoke/` 里有个 `缺陷探针2_插值确认.light`
—— 名字听起来像「预期的失败」，如果它是 known-fail，**要把它排除掉**，否则 smoke 永远红。

### 3) 补 CI

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
  workflow_dispatch:

jobs:
  smoke:
    runs-on: ubuntu-latest
    timeout-minutes: 20
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.12'
      - name: 检出 light 编译器
        run: |
          git clone --depth 1 https://gitcode.com/skywalk163/light.git ../light \
            || git clone --depth 1 https://github.com/skywalk163/light.git ../light
      - name: 冒烟
        run: bash smoke.sh
```
