## 背景

当前系统提示相当长，每个工具的实参键名（如 bash 用「命令」、read_file 用「路径」）都列了一遍，每轮重发是固定开销。这些内容其实只需在模型调用该工具时才需要，不必常驻系统提示。本卡把工具参数键名等细节**下沉到工具的 schema description**，模型调用时才展开，系统提示常驻部分只留核心规则。

## 目标

1. 把各工具的参数键名/实参规范从系统提示常驻区移出，下沉到工具 schema description；
2. 系统提示常驻部分压缩为「核心规则 + 指向详细文档/schema」的短形式；
3. 压缩后模型调用行为不变——参数键名等细节在工具 schema 中仍可被发现。

## 关键设计取舍

压缩要**可验证不丢信息**：参数键名等细节从常驻区移出后，必须在工具 schema description 中可被模型读到；若某信息两者都删则算丢信息，需回填。可用 `src/工具展示.light` 的 token 度量验证节省量。

## 交付物

- 系统提示常驻部分精简版本
- 工具 schema description 的参数细节回填
- `tests/test_T0513_参数下沉.py`

## 验收判据

1. 参数键名等细节从系统提示常驻区移出后，在工具 schema 中可读；
2. `tests/test_R38_工具展示_token.py` 验证系统提示 token 节省量；
3. 模型调用行为不因下沉而改变（能正确读参数键名）；
4. `tests/test_T0448_工具面装配.py` 不回归。

## 红线

- 下沉**不等于删除**：所有移出常驻区的信息须在 schema description 中可读；
- 节省量可度量（复用 `工具展示_token` 测试），可量化交付；
- 不改变任何工具的参数签名与调用方式。
