# 修测试挂死：`run()` 没隔离子进程 stdin

## 一句话

`tests/test_watchdog.py` 输出 `9 passed`，但**进程不退出**，`timeout 15` 三次全部 `exit=124`。
根因不是测试逻辑，是 `hive.py:347 run()` 的 `subprocess.run` 没传 `stdin`。

## 复现（我已跑过，可信）

```bash
cd /home/skywalk/dswork/hive

# 不加 stdin 重定向：3/3 挂死
for i in 1 2 3; do timeout 15 python -m pytest -q tests/test_watchdog.py; echo "exit=$?"; done
# exit=124 / exit=124 / exit=124

# 加 stdin 重定向到 /dev/null：2/2 通过
for i in 1 2; do timeout 20 python -m pytest -q tests/test_watchdog.py </dev/null; echo "exit=$?"; done
# exit=0 / exit=0
```

全量 `pytest` 同样表现：`timeout 300 python -m pytest -q` 被强杀（898 tests collected）。

## 根因

`hive.py:347`：

```python
def run(cmd, cwd=None, check=True, input=None, timeout=None, shell=False, env=None):
    raw_input = input.encode("utf-8") if isinstance(input, str) else input
    try:
        if raw_input is None:
            p = subprocess.run(
                cmd, cwd=str(cwd) if cwd else None, text=True, input=None,
                capture_output=True, timeout=timeout, shell=shell, env=env,
                encoding="utf-8", errors="replace", **no_window_kwargs(),
            )
        else:
            p = subprocess.run(
                cmd, cwd=str(cwd) if cwd else None, text=False, input=raw_input,
                capture_output=True, timeout=timeout, shell=shell, env=env,
                **no_window_kwargs(),
            )
```

**两个分支都没传 `stdin`。** 后果：

1. `subprocess.run(..., capture_output=True)` 内部走 `communicate()`，
   它会一直读到 stdout/stderr 管道 **EOF** 才返回。
2. 没指定 `stdin` 时，子进程**继承父进程的 stdin**。git 会 fork 出 `git-receive-pack`、
   `git upload-pack` 这类后代（实测进程树：`hive.py claim` → `git push` → `sh -c git-receive-pack`）。
3. 这些后代**继承了同一个 stdin fd**，于是父进程自己也不持有管道的唯一写端；
   `communicate()` 等 EOF，而写端还被活着的后代握着 → 永久阻塞。

我抓到的实时进程树（挂住时）：

```
pytest
 └─ python hive.py --dir /tmp/pytest-xxx/hive-a1 claim T-0901 --agent w1
     └─ git push origin 914f547...:refs/heads/claim/T-0901
         └─ /bin/sh -c git-receive-pack '/tmp/pytest-xxx/hive.git' ...
             └─ git-receive-pack /tmp/pytest-xxx/hive.git
```

注意 `hive.py` 本身注释里已经踩过一次同类坑（`hive.py:6707`）：
> `stdin=DEVNULL`：给不到真正的 stdin 时，管道右半边会阻塞在读 stdin 上

**同一个仓库里已经知道这个道理，但 `run()` 这个总出口漏了。**

## 目标

### 1) 主修：`run()` 两个分支都显式隔离 stdin

```python
def run(cmd, cwd=None, check=True, input=None, timeout=None, shell=False, env=None):
    raw_input = input.encode("utf-8") if isinstance(input, str) else input
    # stdin 必须显式给死：不给时子进程继承父进程 stdin，git 的后代进程
    # （receive-pack / upload-pack）会一直握着它；capture_output 内部 communicate()
    # 等管道 EOF → 永久挂住（2026-11-06 实测 test_watchdog 3/3 exit=124）。
    #
    # 只在「没有 input」这一支加 stdin；有 input 时 subprocess.run 会自己设 PIPE，
    # 再显式传 stdin 会 ValueError（stdin and input arguments may not both be used）。
    try:
        if raw_input is None:
            p = subprocess.run(
                cmd, cwd=str(cwd) if cwd else None, text=True, input=None,
                stdin=subprocess.DEVNULL,
                capture_output=True, timeout=timeout, shell=shell, env=env,
                encoding="utf-8", errors="replace", **no_window_kwargs(),
            )
        else:
            p = subprocess.run(
                cmd, cwd=str(cwd) if cwd else None, text=False, input=raw_input,
                capture_output=True, timeout=timeout, shell=shell, env=env,
                **no_window_kwargs(),
            )
```

> ⚠️ **只改 `raw_input is None` 那一支。** 有 `input` 的那支**一个字都别动**：
> `subprocess.run(input=...)` 内部会自己把 `stdin` 设成 `PIPE`，你再显式传
> `stdin=subprocess.PIPE` 会直接抛
> `ValueError: stdin and input arguments may not both be used`（我已实测确认）。
> 这是本卡最容易踩的坑 —— 「两个分支都加 stdin」看起来更对称，但会当场炸。

### 2) 兜底：给测试加超时闸

`hive/pyproject.toml` 里 `[tool.pytest.ini_options]` 目前是空的。加：

```toml
[tool.pytest.ini_options]
timeout = 120
```

需要在 `pyproject.toml` 的 `[project.optional-dependencies]`（或 dev 组）里加 `pytest-timeout`。
⚠️ **如果不想动 `pyproject.toml`**（它是共享文件，容易和别的卡撞），
就新建 `tests/run_pytest.sh`：

```bash
#!/usr/bin/env bash
# 统一测试入口：stdin 静态重定向 + 硬超时。
# 为什么要有这层：hive.py run() 曾因未隔离子进程 stdin 导致 git 后代挂住管道，
# 表现是「测试全绿但不退出」。这里用 </dev/null + timeout 双保险。
set -uo pipefail
cd "$(dirname "$0")/.."
exec timeout "${HIVE_TEST_TIMEOUT:-600}" python -m pytest -q "$@" </dev/null
```

并让本卡 `verify` 全部走它。

### 3) 回归测试：锁住这个坑

新建 `tests/test_run_stdin.py`，至少两条断言：

```python
"""锁住 run() 的 stdin 隔离（T-0261）。

背景：run() 不传 stdin 时，子进程继承父进程 stdin，git 后代持有管道写端，
communicate() 等 EOF 会永久阻塞。这里用一个「读 stdin 且不主动退出」的子进程复现。
"""
import subprocess
import sys
import time

import pytest

import hive


def test_run_does_not_inherit_parent_stdin():
    """run() 必须把 stdin 给成 DEVNULL，子进程读 stdin 立即得到 EOF。"""
    # 子进程读一行 stdin；若 run() 隔离了 stdin，它会立刻得到 EOF 并退出。
    code = "import sys; sys.stdin.read(); print('eof-ok')"
    p = hive.run([sys.executable, "-c", code], timeout=10, check=False)
    assert "eof-ok" in (p.stdout or "")


def test_run_does_not_hang_when_child_spawns_grandchild():
    """子进程再 fork 一个继续持有 stdout 的后代时，run() 不该永久阻塞。"""
    # 孙进程 sleep 后写日志；父进程立刻退出。若不隔离 fd，communicate 会等到孙进程结束。
    code = (
        "import subprocess, sys\n"
        "subprocess.Popen([sys.executable, '-c', 'import time; time.sleep(30)'])\n"
        "print('parent-done')\n"
    )
    start = time.time()
    p = hive.run([sys.executable, "-c", code], timeout=10, check=False)
    elapsed = time.time() - start
    assert "parent-done" in (p.stdout or "")
    assert elapsed < 5, f"run() 阻塞了 {elapsed:.1f}s，stdin/fd 隔离失效"
```

> 这两条要能**先红后绿**：把 `run()` 的 `stdin=DEVNULL` 去掉，第二条应该超时失败。
> 如果去掉后仍然绿，说明测试没有咬住，回头改断言。
