## 目标

实现 `hive_control/plane.py::ControlPlane`：

- 启动：`IncarnationStore.next`、`StateView`、`DownlinkQueue`、`Election`、
  `LeaseBook`、`UplinkQueue`、`Aggregator`、`UplinkSender`、`ControlTcpServer`、
  `DownlinkSender/Receiver`、`WorkerServer`；可注入 transport / peer_provider /
  local_agents / limits。
- 本地 `report_entry`：D5 盖号（incarnation=本 serve，version 单调 +1）→ install；
  Leader：入下行队列，瞬态 / urgent 立即事件下行；Follower：聚合 → 上行队列。
- 安装（上行 / 下行 / 拉取）：只有 `install().installed` 才刷新租约、通知本机 Worker。
- `tick()`：选举 tick / 心跳 / 周期下行 / 续约 / 过期 / 水位缺口增量拉取，
  全部幂等，供测试直接驱动。
- 切主：become_leader 时停上行、租约宽限、开始心跳；leader_lost 时清 target，
  下一个 Leader 出现后重定向；未发上行不丢。
- 人工拉取：独立队列（64）+ 线程池；结果按安装规则合并、通知 Worker、
  **不发下行**（G5）。
- `status()`：enabled / role / leader_id / epoch / multicast_mode / 队列长度 /
  计数器 / 最近错误。
- start/stop 幂等；stop 尽量 flush 一次未发上行。
