# 版本号校验脚本要能管其它仓

## 问题

`light` 自己做得对：

```
$ grep '^name\|^version' pyproject.toml
name = "guangming"
version = "0.4.1"

$ python -m cli.light_unified --version
光明 v0.4.1
```

而且已经有 `scripts/check_version_consistency.py`。但另外几个仓没这个约束：

| 仓库 | 声明 A | 声明 B | 最近 tag | 一致性 |
|---|---|---|---|---|
| `hive` | `hive.py:55` `VERSION = "0.15.2"` | `pyproject.toml:7` `version = "0.1.0"` | `v0.15.2` | ❌ 差两个 minor |
| `lightmem` | — | `go.mod` 无版本 | `v0.1.0`（唯一） | ⚠️ 无法校验 |
| `lightharness` | `CHANGELOG` 最新 `v0.5.0-rc1` | **无 pyproject** | `v0.5.0-rc1` | ⚠️ 无机器可校验点 |
| `lightplugin` | — | **无 pyproject** | `v1.0.0` | ⚠️ 无 |

`hive` 那条最要命：`pip install hive-cli` 装出来是 **0.1.0**，`hive --version` 打印 **0.15.2**。
用户报 bug 时说不清版本。

## 目标

### 1) 把校验脚本改成「可指定仓库路径」

现在它大概率是硬编码相对本仓的。改成支持参数：

```bash
python scripts/check_version_consistency.py                 # 默认校验本仓（行为不变）
python scripts/check_version_consistency.py --repo ../hive  # 校验兄弟仓
```

支持的「版本声明点」，按存在性自动探测：

| 仓 | 探测点 |
|---|---|
| `light` | `pyproject.toml` 的 `version`、`cli.light_unified --version` 输出、`CHANGELOG.md` 首条 |
| `hive` | `hive.py` 的 `VERSION = "..."`、`pyproject.toml` 的 `version` |
| `lightharness` | `CHANGELOG.md` 首条 `## [vX.Y.Z]`（无 pyproject，探测不到就跳过并说明） |
| `lightmem` | 最近 git tag（`git describe --tags --abbrev=0`） |
| `lightplugin` | 最近 git tag |

### 2) 输出要人能读

```
$ python scripts/check_version_consistency.py --repo ../hive
[hive]
  hive.py VERSION      = 0.15.2
  pyproject.toml       = 0.1.0
  最近 tag             = v0.15.2
  ✗ 不一致：pyproject.toml(0.1.0) != hive.py(0.15.2)
  建议：pyproject.toml 改为 0.15.2（以 hive.py 为准，它是运行时真源）

退出码 1
```

**别只输出一行 `False`。** 这个脚本的价值是「告诉人该改哪个文件」，不是「判个红绿」。

### 3) 写 `docs/版本号口径.md`

说清四仓各自的「单一真源」是哪个：

- `light`：`pyproject.toml`（有 `check_version_consistency.py` 守着）
- `hive`：**`hive.py` 的 `VERSION`**（运行时真源）→ `pyproject.toml` 必须跟它
- `lightharness`：`CHANGELOG.md` 首条（建议后续补 pyproject 时以它为准）
- `lightmem` / `lightplugin`：git tag

再写一条铁规：**版本号一个仓只有一个真源，其它地方必须跟它，不许各自拍**。

### 4) 顺手给 `hive` 一个可执行的修复建议（不代改）

本卡**不改 hive 的文件**（那是 T-0272 的范围）。只在 `docs/版本号口径.md` 里写明：

```
hive 的修复：pyproject.toml:7 从 0.1.0 改成 0.15.2，并加一条 CI 检查。
（已拆给 T-0272，本卡不做）
```

## 红线

- 只改 `light` 仓的 `scripts/check_version_consistency.py` 和 `docs/版本号口径.md`
- **不改 `hive` / `lightmem` / `lightharness` / `lightplugin` 的任何文件**（跨仓改动必须走各自任务卡）
- 不改变现有「默认校验本仓」的行为（必须向后兼容，`verify` 里那条就是回归）
- 不写 token / 密钥 / IP
