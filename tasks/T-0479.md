## 背景

今天实测：`默认系统提示文本()` = **2047 字**，其中**没有任何运行环境信息** ——
没有操作系统、没有 shell、没有工作目录、没有当前时间。

后果（都是真实摩擦）：

- 模型不知道自己在 Windows + pwsh 里，会写 `cat/grep/sed` 这类 POSIX 命令，
  然后吃一次 `command not found` 才改；
- 「今天/本周/最近」类任务只能猜日期，`时间上下文.light` 与 `时间工具.light`
  实现了 IANA 校验与 `格式化时间戳/时区偏移文本`，但**只有 `时间工具` 导入了它**，
  系统提示一个字没用上；
- DSH 有 runtime context + 时区策略（`docs/persistence-changes/2026-11-09-sdk-prompt-time-zone.md`），
  本仓这块是空的。

## 目标

新增 `src/提示_环境段.light`（纯文本模块，入参字典，不读全局）：

1. `环境段文本(信息字典)`，按字段渲染，缺字段就**整行省略**（不写「未知」）：
   - `系统`（windows / linux / freebsd / darwin）→ 「操作系统：…；shell：…」；
   - `壳`（pwsh / bash）→ 「命令一律按 <壳> 语法写；路径分隔符工具层统一用 /」；
   - `工作目录` + `项目根` → 「工作目录：…（项目根：…）；相对路径从工作目录解析」；
   - `本地时间` + `时区偏移` → 「当前本地时间：2026-11-25 12:30（UTC+08:00）」；
   - `会话模式`（可选）→ 一行「当前模式：standard + default」。
2. `环境段(信息字典)`：段落别名，返回 `环境段文本`；字段值非字符串 → 视为缺失。
3. 时间格式化复用 `时间上下文.格式化时间戳(现在, 偏移分钟, 时区)` 与
   `时区偏移文本(偏移分钟)`，**不自己拼日期**。
4. 隐私归一：出现 `C:\Users\<name>` / `/home/<name>` 形态的家目录 → 替换成 `<home>`。

## 红线

- 不改 `src/时间上下文.light` / `src/时间工具.light` 的既有导出与断言；
- 不硬编码时区：偏移必须由调用方传（默认 480 只作为缺省参数，不写死在文案里）；
- 不读环境变量里的密钥/令牌，只允许读 `OS` / `SHELL` / `COMSPEC` 这类平台标记（且由调用方传入更佳）；
- 不改 `src/系统提示.light`、`src/总入口.light`（接线归 T-0487 / T-0489）；
- 不许 `git reset --hard` / `push --force` / `--no-verify`。

## 验收

`python -m pytest -q tests/test_T0479_环境段.py` 全过：

- 全字段 → 5–6 行，含「操作系统」「工作目录」「当前本地时间」「UTC+08:00」；
- 缺 `工作目录` → 不出现「工作目录」行；缺 `本地时间` → 不出现时间行；
- 偏移 480 → `+08:00`；偏移 0 → `+00:00`（复用 `时区偏移文本` 的 slice(3) 口径）；
- 家目录串 `C:\Users\skywalk\x` → 输出 `C:\Users\<home>\x`；
- 长度 ≤ 400 字符；字段值给整数/空 → 该行被省略而不是抛错。

反跑：①把缺字段分支改成写「未知」→ 判据红；②手写 `+08:00` 常量 → 「偏移 0」红；
③去掉家目录归一 → 隐私判据红。恢复后全绿。
