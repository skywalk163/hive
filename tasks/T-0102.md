## 背景

Windows 10 VM（192.168.0.86）是四台机器里唯一没接入的。本轮把引导脚本补全，并在 Windows 上跑通一张 hive 仓的卡，证明 Windows 是可用的 worker。

## 目标

1. `windows/bootstrap.ps1`：克隆 hive 仓、装 Python 3（若缺）、配置 git 身份、打印 `hive status` 摘要作为「接入成功」标志；幂等（重复跑不坏）；
2. `docs/操作手册.md` 或 `docs/CHROOT_GUI_AGENTS.md` 补一节「Windows 接入」：Windows 上 worker 用 **manual 模式**（`hive take` + 手工改 + `hive submit`），与 GUI agent 一致；给出 bootstrap.ps1 用法；
3. 在 Windows 上跑通一张卡：README 或 CHANGELOG 加一行并 `hive submit`，把 result 落进 hive（证明 Windows 能完成 end-to-end）。

## 红线

- 不改 light 等仓；Windows VM 上的 hive 仓路径要与 bootstrap.ps1 保持一致。
- 不自动启 worker（manual 模式）。

## 验收

bootstrap.ps1 存在且幂等；文档有 Windows 章节；Windows 上完成至少一张卡（result 落 hive）。
