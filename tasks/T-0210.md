## 症状

源码按**中文**写关键字参数调内置，一大半直接 `TypeError`；能调通的那些纯属形参恰好是中文名。

```
写入文件("/tmp/b.txt", "内容", 编码="utf-8")
  ⇒ TypeError: 写入文件() got an unexpected keyword argument '编码'
读取文件(路径=…) / 分割字符串(文本=…, 分隔符=…)   同样炸
原子写入(…, 权限=空)                               ✅ 通
字典获取(典, 键, 默认=…)  ⇒ 报错还会贴心提示 Did you mean '默认值'?
```

**同一个 `原子写入` 内部就是混的**：`encoding`（英文）+ `权限`（中文）。

## 根因

`stdlib/builtins.py` 191 个顶层函数里 **70 个纯英文形参 / 92 个纯中文形参 / 3 个中英混杂**
（`原子写入`、`序列化JSON`、`设置文件所有者`）。没有「中文关键字 → 形参名」的映射层，
源码写什么关键字就得和 Python 形参逐字相同。

## 影响

文档（`docs/AI编程指南.md`）与 stdlib 的 `.light` 门面写的全是中文形参名，**照抄即红**；
约 43% 的内置没法用中文关键字调用，且**哪些能、哪些不能毫无提示**，只有跑到那一行才炸。

## 期望

1. 每个内置都能用它**文档上写的中文形参名**做关键字调用；
2. 同一函数的形参名**不得中英混杂**；
3. 有一条门禁守着，防再犯。

## 落点（二选一，推荐 ②）

① 给 codegen 加一张「中文别名 → 英文形参」映射表，发射关键字参数时翻译；
② 把 70 个纯英文形参统一改成中文 —— **必须连 boot / LH 两份副本一起同步**
   （`python3 scripts/sync_builtins.py`），且注意**别新增/删除顶层 `def`**
   （地板分母，见 `tests/unit/test_R158_地板证据窗口漂移.py` 的 68/96）。

无论选哪条，**先加门禁**：扫 `stdlib/builtins.py` 每个函数的形参，
（a）中文/英文不得混杂；（b）每个内置必须能用中文关键字调用成功。

## 验收

新增 `tests/unit/test_LH34_中文关键字参数.py`：

1. 至少覆盖 `读取文件/写入文件/分割字符串/原子写入/字典获取` 五个的中文关键字调用全部成功；
2. 一条**参数化门禁用例**：对 `stdlib/builtins.py` 里每个公开函数，用它的中文形参名
   （缺中文名则判定为「不合规」并列出）尝试关键字调用 —— 全通过；
3. `python3 scripts/sync_builtins.py` 后 `tests/unit/test_builtins_drift.py` 仍全绿
   （boot 与 LH 两份副本的名字集合与真源一致）。

## 边界

- 改形参名会动到三份副本，**必须跑 `sync_builtins.py`**，别手改副本。
- 不要为了过门禁去删内置。
