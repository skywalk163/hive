> 在 Windows worker（cmd.exe + shell=True）上必然 exit 255，产物合格也会被判 failed
> （T-0221 / T-0222 已因此各卡一轮）。现统一改为：
> - 正向匹配：`git grep -q ... -- <文件>`
> - 反向匹配：`git grep -L ... -- <文件>`（`-L` 列出**不含**匹配的文件，无匹配即 exit 0）

> - 文件存在：`test -f <路径>`（hive_compat 垫片认识这个）
> 注意：`git grep` 只搜**已跟踪**文件，新增文件要先 `git add`。
