## 症状

`src/linter/builtins.py` 的内置名清单里有 `集合创建`、`字典设置默认值` ——
写进源码**编译能通过**（linter 认为那是内置，所以不报未定义名），
运行期却是 `NameError`：

```
设 s 为 集合创建([1,2,2,3])     ⇒ name '集合创建' is not defined
字典设置默认值(d, "b", 5)        ⇒ name '字典设置默认值' is not defined
```

## 根因

清单与 `stdlib/builtins.py` 的真身**没有对拍**。`tests/unit/test_文档内置名存在性.py`
只查**文档里出现的名字**，**不查 linter 清单里的名字** —— 清单这一侧是裸奔的。

## 影响

与 LH-21（= L-251）同源的假绿：linter 因为「它是内置」而放行，
错误一路留到运行期深处才炸，而且炸在离书写点很远的地方。

## 期望

清单里登记的每一个名字，都必须能在运行期解析到；对不上的要么补实现、要么从清单里摘掉。

## 落点

- `tests/unit/test_LH40_清单对拍.py`（新增）：把 `src/linter/builtins.py` 的名字集合
  纳入与 `test_文档内置名存在性.py` **同款**的存在性门禁 —— 逐个在运行期解析；
- `src/linter/builtins.py`：清掉真不存在的名字（**或者**给它们补上真实现 —— 若补实现，
  注意别在 `stdlib/builtins.py` 里新增顶层 `def`，走 `_t5b_runtime.py` 通道）。

## 验收

1. 新门禁用例：清单中每个名字都能在运行期解析到（当前会红，红出来的就是待清理项）；
2. 清理后该用例全绿，且 `tests/unit/test_builtins_drift.py` 不受影响；
3. 卡里必须**列出**清理掉/补齐的名字清单与各自理由，别静默删名。

## 边界

- 只动清单与这条新门禁。`test_文档内置名存在性.py` 的既有断言不许削弱。
