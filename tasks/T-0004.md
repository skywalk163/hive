## 背景

`vscode-extension/snippets/light.json` 现在有 34 个片段，覆盖 L1/L2 为主，
缺 L3（SQL）、L4（Python）和资源管理（与 ... 为 ...）的片段。

## 要做什么

只改 `vscode-extension/snippets/light.json`，在文件末尾、最后一个条目之后追加
下面 4 个片段（保持原有 34 个不变，不要重排）：

```json
"引 SQL 块": {
    "prefix": "引SQL",
    "body": [
        "引 SQL:",
        "    ${1:SELECT * FROM 表名;}"
    ],
    "description": "L3 内嵌 SQL 块"
},
"引 Python 块": {
    "prefix": "引Python",
    "body": [
        "引 Python:",
        "    ${1:import ...}",
        "    出 ${2:结果}"
    ],
    "description": "L4 沙箱引用 Python"
},
"与资源": {
    "prefix": "与",
    "body": [
        "与 ${1:表达式} 为 ${2:名字}:",
        "    ${3:代码}"
    ],
    "description": "资源管理：与 ... 为 ..."
},
"匿名函数": {
    "prefix": "匿名",
    "body": "匿名(${1:x}): ${2:x * 2}",
    "description": "单表达式匿名函数"
}
```
