# 会话细节数据面：开始/完成时刻、耗时、tokens/s 吞吐

## 背景

`src/代理.light` 已经把 `耗时秒` 算出来了，写在 6 处轮次结果里
（486/492/503/506/509/514 同步路径，564/570/583/586/589/594 异步路径），
但**没有任何消费者**：

- 非流式：`src/web服务器.light:584-587` 只取 token 与错误，`耗时秒` 被丢弃；
- 流式：`web服务器.light:2084 载具["结果"] 为 结果` 存了，但 `推流实现`(2115-2160) 从不读 `载具["结果"]`；
- 持久化：`增量保存`（`总入口.light:237`）按事件追加，轮次结果不进事件数据。

所以 tokens/s 这 4 个字符**从来不存在于任何一层**，不是前端算错了。

时间戳现状（口径有两个，别混用）：

| 数据 | 位置 | 形态 |
|---|---|---|
| 会话创建时间（索引） | `src/会话存储.light:193` | ISO 串 `%Y-%m-%dT%H:%M:%S`（`取现在时间` 92） |
| 会话最后更新（索引） | `193` 初值、`220` 每次追加刷新 | ISO 串 |
| 会话头创建时间（日志头） | `src/会话.light:60` | **`时间戳()` 浮点秒** |

`["种类":"统计","本轮输入","本轮输出","累计总","花费","上下文使用率"]` —— 无时间、无耗时、无速率。

## 要做什么

### 1) 新增 `src/会话细节.light`（本卡独占，段落前缀 `时`）

纯逻辑格式化 + 计时聚合，**不导入 web/代理**：

- `时造计时器()` → `{开始时刻, 结束时刻, 耗时秒}`，`时开始计时` / `时结束计时`（用 `时间戳()`）。
- `时算速率(输出token, 耗时秒)` → 浮点 tokens/s；`耗时秒 <= 0` 时要返回 0 而不是抛错
  （除零是这里唯一的事故点，必须有判据）。
- `时造细节行(细节表)` → 给人看的中文一行，形如
  `开始 2026-11-19 23:01:05 · 完成 23:01:41 · 36.2s · 128 tok/s`。
- `时格式化时刻(浮点秒)` → `HH:MM:SS`（本地时区，用既有 `日期时间`/`时间管理` 能力，不要自造格式化）。
- `时补统计字段(统计表, 细节)` → 返回**扩字段后的统计字典**，新增键：
  `"开始时刻"`、`"完成时刻"`、`"耗时秒"`、`"速率"`。
  **这是本卡交付给 T-0407 的核心接口**：T-0407 只需在 `生成统计事件`(436) 里
  调一次 `时补统计字段(原统计, 己.最近轮次细节)`。
- `时从轮次结果取细节(轮次结果, 开始时刻)` → 从代理返回的 `耗时秒`/`输出token` 组装细节表
  （**不要自己再计时**，`代理.light` 已经算过了，重复计时会差一截）。

### 2) `src/会话存储.light`（本卡独占）

### 3) 新增 `tests/test_T0404_会话细节.py`

- `时算速率`：正常值、`耗时秒 == 0`、`耗时秒 < 0`、`输出token == 0` 四种；
- `时格式化时刻`：已知浮点秒 → 期望 `HH:MM:SS`（用固定值，别用 `现在`）；
- `时造细节行`：完整 / 缺完成时刻 / 缺速率 三种形态；
- `时补统计字段`：原字典 6 个键一个不少 + 新增 4 个键，且**不修改入参字典**（纯函数）；

## 附注 A：「光明」写法禁令（照抄现状规避写法，成本最低）

- 段落一律块形式：**禁 `段落 X: 返回 …` 单行函数**（生成器缩进会累积）。
- 字典/列表字面量一律**单行**；嵌套字面量内不写 `\n`（用 `chr(10)`）；字面量不直接当实参先 `设` 变量。
- **单字变量名全禁**（`若 则 否 是 段 出 导 遍 对 跳 过 试 捕 抛 终 返 配 己 自 设 为 从 当 空 长 首 末 余 父 常 并 与 且 或 的 在 到 现 例 步 断 新 接 承 引 掷 跃 非 真`）。
- 标识符不得被关键字序列完全切分（`错误己` 会炸，`错误甲` 正常）；不用「为」字入标识符；
  避开含 `等待` 的标识符；成员名避开 `模/模型/模式/工具/事件/类型/原因/取/生成/新建` 等词根。
- 成员赋值一律 `设 己.X 为 …`（裸 `己.X 为 …` 会编成 `==`）。
- 缺键 `d[k]` 直接抛 `键错误` → 用 `字典获取(d, k, 缺省)` 或 `字典包含键` 守卫。
- `空` 是 `None` 不是 `""`，判空串写 `x != "" 且 x != 空`（照抄 `web服务器.light:452/522/527`）。
- `/` 是浮点除法，切片/下标前先 `整数()`。
- **段落名会与依赖模块内联后冲突**（`src/代理循环.light:10-12` 已记）：新模块段落统一加 2 字前缀
  （本批约定：`续`=目标续跑、`压`=压缩升级、`模`不许用→用 `式`、`队`=会话队列、`时`=会话细节）。
- 循环依赖用 `导入 模块` + `模块.段落()` 点号调用，不要 `从 X 导入 名`。
- 新模块名全仓唯一（`src/` 与 `stdlib/` 都要查）。
