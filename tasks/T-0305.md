## 背景

母文档 §5.1：子节点把聚合结果 TCP 单播到 Leader 的 `port+1`；失败指数退避
500ms→10s，切主重定向且不丢队列。本卡只做发送器（监听/拉取在 T-0306）。

先读 `docs/控制面v0.5-实现约定.md` §3.4。

## 目标

实现 `hive_control/uplink.py::UplinkSender`：

- 构造：`queue`、`target` provider、`limits`、`rxmt_interval`、`clock`；
- `set_target(host, port)` 线程安全；target 为 None 时不发；
- `start/stop` 后台线程；`send_once()` 供测试：取空队列、连接、逐行发 `entry`；
- 连接失败 / 半写失败：整批放回队列（不得丢），按 `rxmt_interval` 指数退避，
  上限 10s；成功后清零；
- 连接保持复用，失败即关闭重建；发送只发 `entry` 行，不混入 pull；
- `status()` 返回 `target / failures / backoff / sent / last_error`。

## 测试（`tests/test_control_uplink.py`）

用 127.0.0.1 临时端口写一个收集行的小 TCP server：

- `send_once` 发出全部条目且行可解析；
- 目标不可达时不丢队列、backoff 增长；
- server 起来后自动补发；
- `set_target` 切到第二个 server 后新条目去新目标；
- stop 幂等。

## 红线

不实现拉取、组播、选举；不改共享骨架；测试不 sleep 2s（注入小 rxmt_interval/clock）。
