## 一、现状与为什么必须按本卡步骤做

- 主控 fb98 目前是**单节点** `leader`、term **614**、`peers=1 / quorum=1`，
  幽灵身份已从磁盘清除（`state.json.leader_id = fb98-bc650fb5`）。
- 104（Windows，机器名 `DESKTOP-6LFQUO8`，节点 id `DESKTOP-6LFQUO8-8a3bf94c`）
  目前**整机停机**：8788 / 8790 / 22 / 445 全部不通。
- 历史故障：`state.json` 里残留过旧 Mac 身份 `laiweilideMacBook-Air-20c3af99`，
  且 `leader_url` 指向 104。2026-11-07 曾出现「104 端口开着、`/` 秒回 404，
  但 `/api/cluster/health` 与 `/state` 10 秒超时 0 字节」，导致两节点互判 dead、
  term 每分钟涨 2（585→598）、leader 来回跳、store 写被同步复制拖死。
  高度怀疑是**关开时旧进程没死透、两个 hived 抢同一个 8788 与 sqlite**。
- 因此：**先验证并清理磁盘 → 杀干净进程 → 单进程启动 → 立刻量响应时间**。

**红线（做了就是返工）**
- 不要直接跑 `win-sync-restart.ps1 -Apply` 或 `cluster restart`：它们内部会再拉一个
  节点进程，和残留/自愈进程各占一个，正是上次卡死的形态。
- 不要在服务还活着的时候手工改 `state.json`：运行时 `_persist()` 每秒用内存覆盖磁盘，
  改了必被冲掉。**现在整机停着，是改盘的唯一干净窗口**。
- 不要删 `events` / `progress` / `leases` 里的旧 Mac 字符串：那些只是历史审计记录，
  不是活跃指针。只清顶层 leader 相关字段与节点表重复身份。

## 三、分支 A：`leader_id` 仍是 `laiweilideMacBook-Air-20c3af99` → 先清盘

若第二步发现幽灵残留，**必须先清盘再启动**，否则一开机就会广播回来。
整段可粘贴（含备份、无 BOM 写回）：

```powershell
$ErrorActionPreference = 'Stop'
$dir   = Join-Path $env:USERPROFILE '.hive\cluster'
$state = Join-Path $dir 'state.json'
$node  = Join-Path $dir 'node.json'
Copy-Item $state "$state.bak-T0283" -Force
Copy-Item $node  "$node.bak-T0283" -Force

$j  = Get-Content $state -Raw -Encoding UTF8 | ConvertFrom-Json
$nj = Get-Content $node  -Raw -Encoding UTF8 | ConvertFrom-Json

$j.leader_id                = $null
$j.leader_url               = $null
$j.leader_lease_until       = ''
$j.leader_lease_until_epoch = 0
$j.lease_grace_until        = ''
$j.lease_grace_until_epoch  = 0
$j.voted_for                = $null
$j.PSObject.Properties.Remove('snapshot')

# 节点表：删掉「URL 与本机相同、但 id 不是本机身份」的旧记录
$me = $nj.id
$selfUrl = ($j.nodes.PSObject.Properties | Where-Object { $_.Name -eq $me }).Value.url
foreach ($p in @($j.nodes.PSObject.Properties)) {
    if ($p.Name -ne $me -and $p.Value.url -and $selfUrl -and
        ($p.Value.url.TrimEnd('/') -eq $selfUrl.TrimEnd('/'))) {
        "删除旧身份: $($p.Name) -> $($p.Value.url)"
        $j.nodes.PSObject.Properties.Remove($p.Name)
    }
}

# 必须 UTF-8 无 BOM：PowerShell 5.1 的 Set-Content -Encoding UTF8 会加 BOM，
# Python 的 json.load(encoding='utf-8') 读 BOM 会直接崩。
$txt = $j | ConvertTo-Json -Depth 30
[IO.File]::WriteAllText($state, $txt, (New-Object Text.UTF8Encoding($false)))

$chk = Get-Content $state -Raw -Encoding UTF8 | ConvertFrom-Json
"改后 leader_id = $($chk.leader_id)  nodes = $(@($chk.nodes.PSObject.Properties).Count)"
```

若 `node.json` 的 `id` / `name` 不对，改成
`DESKTOP-6LFQUO8-8a3bf94c` / `DESKTOP-6LFQUO8`（同样用无 BOM 写回），
否则 `Identity.__init__` 会继续用旧身份注册自己。

**分支 B**：第二步判据全部通过 → 跳过本节，直接进入第四节。
