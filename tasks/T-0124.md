## 背景

Windows 机器（192.168.0.86）是唯一没接入的。`windows/bootstrap.ps1` 做了 clone、
注册 agent、装计划任务，但**没告诉 agent 怎么连上 hive** —— 计划任务是给
「没有 agent CLI 的机器」用的老路，现在 MCP 已经能做 worker 视角的全部事
（查卡/领卡/交活/放弃），Windows 上的 GUI agent 应该走 MCP，不需要 worker。

## 目标

1. `bootstrap.ps1` 在注册完 agent 后**直接输出 MCP 客户端配置 JSON**
   （打印到屏幕 + 写成 `mcp-config-<agent>.json`），并写清接下来调哪几个工具。
2. `bootstrap.ps1` 的 `agent add` 带上 `--abilities`（新增 `-Abilities` 参数）——
   否则 dispatch 按能力匹配时永远选不中这台机器。
3. `windows/README.md` 补一节「用 MCP 接入」：和 manual worker 的区别、
   配置粘到哪、典型调用序列。
4. 说明清楚：Windows 这类没有 agent CLI 的机器，**MCP 路子和 worker 二选一**，
   不要同时用（会重复领卡）。

## 红线

- 不改 light 等仓；不改 fb5 runner。
- PowerShell 脚本只能做静态检查（本机没有 pwsh），**必须在文档里说明未在真机验证过**。
