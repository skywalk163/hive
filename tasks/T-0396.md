# 新会话面板：目录选择器 + 模式/权限预选

## 背景

DSH 的落地页就是「新会话面板」：目录、模式、权限、附件、模型都在开聊前可选。
lightharness 的落地页只有输入框：目录必须去设置页改全局（`webui/settings.js:270-310`
的「工作目录」卡片），模式/权限要等会话建出来后才在输入区/顶栏切。用户实测原话：
「无法直接设置目录，需要到设置里面去改，而且那个是全局变量」。

T-0395 已让后端支持会话级 cwd，这卡补前端入口与只读校验。

## 要做什么

1. 输入区左上增加「目录」chip（显示待建/当前会话的 cwd；未选时显示「默认」）。
   点击弹层包含：
   - 手输绝对路径输入框；
   - 最近 5 条目录（`localStorage` 键 `lh.recentCwd`，只存路径字符串）；
   - 只读校验按钮/失焦校验；
   - 「设为全局默认」按钮（调既有 `POST /api/cwd`，明确提示这是全局生效）。
2. 新增 `GET /api/cwd/check?路径=<urlencoded>`：只读校验，返回
   `{存在, 是目录, 可读, 绝对路径, 错误}`。**绝不 chdir、绝不写 settings.json**；
   相对路径按服务进程 cwd 解析后回显绝对路径；鉴权口径与其它 GET 一致。
3. 空会话（尚无 `session_id`）选目录后，chip 显示「本会话：/x」；首条消息 body 携带
   `工作目录`（T-0395 已支持）；服务端 400 时 chip 标红并显示理由，不得静默丢掉目录。
4. 面板内提供「模式」（standard/cordis/ptc/minimal）与「权限」（全放行/按类别/全拒绝/自定义）
   下拉。**本卡只做 UI 暂存与随请求携带**；权限真正按会话生效是 T-0397，不得在未落库时
   假装已生效（UI 要有「全局默认」态）。
5. 「＋ 新会话」进入同一个空状态，不立刻 `POST /api/sessions`（避免再产生空会话）；
   若保留立即创建路径，必须把当前目录传进去（不能继续只传 `标题`）。
6. 样式跟 `webui/settings.css` 的 token 走，零第三方库，不引 npm 依赖。

## 不要做什么（红线）

- 不选目录 = 全局默认，行为必须与现在完全一致（老用户零感知）。
- `GET /api/cwd/check` 不得有副作用；不得复用 `POST /api/cwd` 来实现校验。
- 不改 `webui/sidebar.js` 的列表协议（`标题/消息数/文件` 等键不动）。
- 不引第三方 UI 库；不动 `index.html` 既有 id（测试与 `app.js` 都靠它）。

## 完成标准

- 两个 `node --check` 通过；`tests/test_T0396_新建会话目录选择.py` 覆盖
  check 端点的存在/不存在/是文件/相对路径/无副作用（校验前后 settings.json 与进程 cwd 不变）。
- 浏览器手工冒烟（summary 贴结果或截图）：新建 → 选目录 → 发一条消息 → 会话头/索引 cwd 正确；
  刷新后 chip 仍显示该目录；选择非法目录时 chip 标红且消息未发出。
- `git show --stat HEAD` 只覆盖卡面 `paths`。
