## 背景

T-0508 给工具注册表加了可逆性四级分级元数据（`read_only / reversible / semi / irreversible`），并产出 `docs/风险分级规范.light.md` 与判据 `tests/test_T0508_可逆性分级.py`。当时判据把计数**写死**为 `168 / 75 / 40 / 5 / 48`（对应带插件的主检出口径）。

`docs/风险分级规范.light.md:62`「可逆性表 168 条」与源码一致（`src/工具面装配.light` 静态表确有 168 项，是超集），但 `:72`「本卡实测 168 / 未分级 0」、`:196-198`「当前基线（真实注册表 168 工具…75/40/5/48）」和判据断言都已过时——**这是一条确定性红灯，至今未修**（`git log -- tests/test_T0508_可逆性分级.py` 只有 T-0508 的两次提交）。

参见 `docs/功能对标/T0496-T0531_工具面强化批次收口报告.md` §3.2 第 1 项。
