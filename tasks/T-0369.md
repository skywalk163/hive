## 上游语义（三条）

**#14 批量追加**：`Session.append` 既收「单个带类型事件」也收「事件元组数组」；单事件调用返回一个事件，数组调用返回数组。
普通单事件调用不变；日志格式**不变**。

**#13 运行时上下文提醒**：新写入且 `source.kind:'runtime-context'` 的 `user/message` 把文本包进 `<system-reminder>`；
首份快照介绍当前会话、**不宣称覆盖更早上下文**；后续快照明确覆盖「对话摘要保留的上下文」；清空提醒带 `form:'snapshot'` 与 `sections:[]`。
无 `source.sections` 的旧记录在**下次获准请求**刷新一次（加一条消息，但不改写请求前缀）；旧条目未变则不因文案刷新。

**#15 中断默认关**：base 与 Web 的 `standard`/`cordis`/`ptc` preset 给 `tool-subagent-control` 设 `config.interrupt: false`，
模型工具定义里**没有** `interrupt_agent`（含 Team 模式）；消息/发现/收件箱等待与服务端中断 API 仍可用；
**插件自身默认仍为 true**，省略该配置的独立组合仍提供中断工具。

## 语言坑（光明语言，2026-11 实测）

1. `导出 a b c` 行末不能加句号（报「无法识别的语法元素 '.'」）。
2. 字符串不解释 `\uXXXX`：写真实字符；串内引号写 `\"`。
3. 不支持匿名函数 `段落() 返回 x` → 用具名包装段落。
4. `设 f(x) 为 v` 非法；下标/成员赋值写 `表[位] 为 值`。
5. 变量名避开关键字尾巴（`合并为` / `等待` / `映射`）。
6. `写` 只吃字面量或已赋值变量。
7. 跨模块未捕获异常定位块会错位 → 断言用 `转字符串(异常值)` 比消息。
