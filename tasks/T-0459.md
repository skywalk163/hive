# 语法卡三层重写：从 spec 派生，不许再写 v3.2

## 背景（实测）

```
$ python -m cli.light ai card | wc -c
1013                     # 正文 ≈700 字
```

输出第一行写的是「**光明v3.2速查**」，正文只有 L1 双字体（`如果`/`遍历`），**没有一个 stdlib 函数名**，也没有 L0 三十字、L2 单字、L3 领域块、类型标注。

而 `tools/ai_copilot/syntax_card.py` 的模块 docstring 自述："从 keywords.py 和 stdlib/builtins.py 自动提取 **v3.2** 语法的精简参照"——它是**硬编码模板**，不是从 `spec/light.spec.json` 派生的，所以版本和语法都停在三版前。

这是 agent 唯一的"开机记忆"，却是最旧的一份。同时另一头 `docs/AI编程指南.md` 有 4.8 万字（≈3.5 万 token），塞不进任何 prompt。

## 要做什么

1. 在 `tools/ai_copilot/syntax_card.py` 里实现**三层**，`generate_syntax_card(level=...)`：

   | level | 字数目标 | 放什么 |
   |---|---|---|
   | `compact` | ≤300 汉字 | 6 条硬规则 + L0 三十字分组 + 一个最小可跑例子 |
   | `standard` | ≤3000 汉字 | compact + 控制流/段落/类/异常/导入 + stdlib top50（**函数名逐个列出**）+ 14 条暗坑一行一条 |
   | `full` | 索引 | 不给正文，给 `docs/ai/` 三个链接 + `light ai snippets` 用法 |

2. **内容必须从 `spec/light.spec.json` 派生**：`keywords` / `l0_core` / `stdlib` / `operators` / `diagnostics` 都在里面。版本号从 `src/version.py` 读。**禁止任何硬编码的 `v3.2`**（`grep -c "v3\.2" tools/ai_copilot/syntax_card.py` 必须是 0）。

3. `compact` 顶部必须有「**给 agent 的 6 条硬规则**」，其中至少包含这两条实测坑：
   - `读取(x)` 编译成 `input(x)`（等 stdin），读文件要用 `读取文件`
   - 冒号必选、块靠缩进，`print` → `打印`

4. `docs/ai/` 下放三层卡的可读版本（`compact.md` / `standard.md` / `README.md`），由生成器产出，**与生成结果逐字一致**（测试断言两边相等，防止文档腐烂）。

5. `tests/test_syntax_card_rank.py` 是快照测试，**你的 paths 包含它，按新输出更新快照**（不要为了让旧快照绿而保留旧文案）。

## 不要做什么

- 不改 `cli/light.py`（T-0464 接 `--level` 开关）
- 不改 `spec/light.spec.json`（只读）
- 不复制第二份关键字表：所有事实从 spec 取，取不到就在卡里留空并注明
- 不把 4.8 万字指南搬进卡里

## 完成标准

- `tests/test_T0459_aeicard.py`：
  - `compact` ≤300 汉字、`standard` ≤3000 汉字（按 `len()` 计）
  - 三个 level 都**不含** `v3.2`；`standard` 含当前版本号（从 `src/version.py` 读，断言相等而不是写死 `0.4.2`）
  - `standard` 含 `读取文件`、`段落`、`若`、`引 SQL`
  - `docs/ai/*.md` 与生成函数输出逐字一致
- `tests/test_syntax_card_rank.py` 快照已更新且绿
