# 目标机实测（5 代酷睿 / AVX2）补 V6

## 背景

T-0334 报告 V6 **blocked**：全集群没有 Broadwell 机器；两台验收机都是
Xeon E5-2643 v2（Ivy Bridge，无 AVX2）。卡面明令不许拿本机数字冒充目标机。

## 目标

- 在一台真 5 代酷睿（Broadwell，`sysctl -a | grep avx2` 有 `avx2`；Linux 用
  `lscpu`/`/proc/cpuinfo`）上跑：
  `PYTHONPATH=src python scripts/bench.py --config configs/demo-3m.json --tokens 200`
  至少 3 次；记录 tok/s、ms/token、峰值内存、CPU 型号/频率/线程数、OS、Python/torch 版本；
- T-0341 合入后再跑一次 `make demo`，验证端到端；
- `reports/目标机实测.md`：命令、原始输出、是否 ≥200、与 Ivy Bridge 本机对比；
- 拿不到机器就保持 blocked，**不许编数字**。

## 红线

- 不许用 Ivy Bridge、云主机通用 vCPU 或其他架构冒充 Broadwell；
- 不许改 bench 口径；
- 不许把「本机保守下界达标」当目标机达标。

## 验收

- 报告里有目标机 CPU flags（含 avx2）与 3 次原始输出；
- 只有真机实测完成后才 unblock → done。
