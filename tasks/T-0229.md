根 go.mod 有 `replace github.com/lightmem/kernel => ./kernel`。replace 指令在 `go install ...@version` 场景下会被忽略，导致外部用户装不了。

两条路，择一：
  a) 把 kernel 作为子模块正式发布（模块路径可解析），根模块去掉 replace；
  b) 若短期做不到，则在 README 明确写「只能 clone 后 build」，并同时提供预编译二进制（见另一张卡）。

判据：干净机器 `go install github.com/skywalk163/lightmem/kernel/cmd/lightmem-kernel@latest` 成功。

---

> **判据口径（2026-11-02 统一修正）**：原判据含 `grep` / `!` / `$(...)` 等 POSIX 写法，
> 在 Windows worker（cmd.exe + shell=True）上必然 exit 255，产物合格也会被判 failed
> （T-0221 / T-0222 已因此各卡一轮）。现统一改为：
> - 正向匹配：`git grep -q ... -- <文件>`
> - 反向匹配：`git grep -L ... -- <文件>`（`-L` 列出**不含**匹配的文件，无匹配即 exit 0）
> - 判断 tag 存在：`git rev-parse -q --verify refs/tags/<tag>`
> - 文件存在：`test -f <路径>`（hive_compat 垫片认识这个）
> 注意：`git grep` 只搜**已跟踪**文件，新增文件要先 `git add`。
