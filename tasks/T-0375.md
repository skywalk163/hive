# 64K 表补 `<PY>` / `<LIGHT>` 段标记并重建

> 来源：T-0373 卡面 §五-5「若与 T-0371 同时改词表，**必须串行**：T-0371 的
> `<PY>`/`<LIGHT>` 标记也要在 64K 表里存在，否则两卡合并后测试会红」。
> 实际执行时两卡并行：T-0373 基于 `5344e52`（T-0371 未合入）构建，产物里
> `64000/64001` 是 `<RSV:0473>` / `<RSV:0474>`，与 `vocab.py::SEGMENT_TOKEN_IDS`
> 声明的 `<PY>=64000` / `<LIGHT>=64001` 冲突。

## 一、实测现状（合入后 main `b62c468`）

```
data/vocab_64k.json:  [64000]='<RSV:0473>'  [64001]='<RSV:0474>'
                      '<PY>' ∉ tokens, '<LIGHT>' ∉ tokens
vocab.py:             SEGMENT_TOKEN_IDS = {'<PY>': 64000, '<LIGHT>': 64001}
```

后果不是测试红（现有 64K 用例写于 T-0371 之前，没断言段标记），而是**语义错位**：
拿 64K 表 encode `<PY>` 会落到 UNK，64K 训练一上就静默丢掉段边界。

T-0373 报告 §九-1 说「重跑 `--build-64k` 即可带上」，**这句不成立**——
`vocab_build.py` 只读 `STRUCTURE_MARKERS`，从未读 `SEGMENT_MARKERS`。

## 二、要做什么

1. `vocab_build.py` 的 64K 装配里把段标记排进 `reserved` 槽**头部**：
   ```python
   segment = [tok for tok, _ in sorted(SEGMENT_MARKERS.items(), key=lambda kv: kv[1])]
   structure = list(STRUCTURE_MARKERS)
   reserved_own_quota = quotas["reserved"] - len(segment) - len(structure) - 2  # UNK/PAD
   reserved_own = segment + list(RESERVED_SPECIALS) + [f"<RSV:{i:04d}>" ...]
   ```
   `reserved` 总额仍 1536，八行预算与 65536 总和一行不改；`slot_offsets()["reserved"]`
   仍从 64000 起，因此 `<PY>`/`<LIGHT>` 天然落在 64000/64001。
2. `--check-64k` 增加两条判据：段标记 id 必须等于 `SEGMENT_TOKEN_IDS`；`reserved`
   头部前两个 token 必须是 `['<PY>', '<LIGHT>']`。
3. 重建 `data/vocab_64k.json` + `manifest`（逐槽 sha256 全变，属预期），更新报告里
   的 sha/占用表；`docs/词表预算.md` §六 与 §七 交叉引用保持一致。
4. `tests/test_demo_vocab.py` 新增：64K 表里 `<PY>=64000`/`<LIGHT>=64001`、
   `budget.segment_id_range() == (64000, 64002)`、`DemoVocab` 读 64K 表后
   `encode("<PY>…<LIGHT>…")` 不产生 UNK。

## 三、完成标准

```bash
PYTHONPATH=src python3 -m pytest -q tests/                                  # 0 failed
PYTHONPATH=src python3 -m lightprism.demo.vocab_build --check-64k data/vocab_64k.json  # 全绿
PYTHONPATH=src python3 -m lightprism budget --json                          # issues=[]
python3 -c "import json;t=json.load(open('data/vocab_64k.json'))['tokens'];print(t[64000],t[64001])"
#   期望：<PY> <LIGHT>
```

## 四、禁止

1. 不许只改 JSON 手搓两个 token 了事——manifest 的逐槽 sha256 与来源分档必须与重建一致。
2. 不许把 `reserved` 扩成 1538 来腾位置；总额 65536 不动。
3. 不许顺手改 `data/unified/vocab_4096.json`（4096 侧 T-0371 已落，方案 b 不动）。
