# CPU 重训决策层：跑够步数 + 合并对照语料 + 真标签

> 依据：v2 整合稿 §三 / §五 / §八。依赖 **T-0346**（决策日志）。
> 本卡在 **CPU / FreeBSD** 上跑（约 3–6h），**不是 OpenI / V100 专项**；
> OpenI 方向是 T-0348，已按交办方要求 shelve 后置。

## 背景（实测）

- `reports/训练报告.md`：50 步 × 8 × 512 ≈ **20.5 万 token**，只覆盖语料约 1/5 遍；
  loss 8.02→5.72、val 仍在降，**没有观察到过拟合起点**。实测 199s / 50 步
  → 3000 步约 3.3h，落在 T-0332 的 6h 上限内。跑够之前不下「3.4M 不够」的结论。
- `data/sft/` 363 条 SFT 被 1983 个语料块淹没，控制 token 占比 **0.18%**
  （方案要求 1–2%）；`train_openi.py --self-check` 决策密度 **0.083%**。
- `light/tools/ai_copilot/sft_dataset.jsonl` 有 **2254 条** Python↔光明真实平行语料
  （另有 `corpus_harness.jsonl` 551 条工程体）——是真实对照，不是模型编的。
- 光明官方 AI 流水线本就是「需求 → Python → 小模型**翻译** → `light ai check` 验证」，
  翻译比端到端创作容易一个数量级。

## 要做的事

### 1. 统一数据目录（唯一事实源）

`data/unified/` 放 `vocab_4096.json` / `json_tasks.jsonl` / `code_tasks.jsonl` /
`err_tasks.jsonl` / T-0346 导出的 `decisions.jsonl`。
`train_demo.py` 与后续 `train_openi.py --data-dir` 都从这里读，消掉
2902 vs 4096 词表口径差（或明确声明并存并各自标口径）。

### 2. 合并数据、把任务改成「翻译」

- 并入 2254 条 Python↔光明对照 + 551 条工程体，训练目标改为
  「Python 片段 → 光明片段」+「决策 → 代码 → 验证」序列。
- 决策 / 验证标签**只用 T-0346 的真实运行日志**，按方案一 §4.3 导出。
- **收缩**输出空间：决策点 / 验证码只保留日志里真出现过的 2–3 类，
  不硬凑 7 个决策点 / 8 个验证码（当前 light 版本 7 类 ERR 不可达）。
  目标把决策密度从 0.083% 提到 1% 量级。

### 3. 跑够训练

- 3000–5000 步、CPU 单线程口径，lr schedule 按 epoch 重设
  （50 步余弦意味着大半训练在低 lr，别沿用）。
- 控制 token 加权 / 提高 SFT 混合比；空白处理可选做骨架化（连续缩进折叠成
  `INDENT:n`，或由确定性 formatter 重建），报告里写清是否做、对空格塌缩的影响。
- **记录每步 train loss、每 N 步 val loss、过拟合起始步**。
- checkpoint 必须含 `base_vocab` 本体（v0.2.0 修过的坑）。

### 4. 冒烟与报告

- `--smoke` 固定 prompt 生成 32 token：不崩、非空、可解析。
- `reports/训练报告_v2.md`：语料统计、loss 曲线、过拟合起点、
  **成功与失败样例都贴**、耗时与硬件、与 50 步基线的对比。

## 完成标准

- 新 checkpoint 可加载，`--smoke` 通过
- `python3 -m pytest -q tests/test_train_demo.py` 通过（含新增决策序列用例）
- 报告含上述全部内容；决策密度、控制 token 占比写明口径
- 不破坏 `test_kv_cache.py` / `test_model.py`

## 禁止

- **不超过 6 小时**；跑不完减小步数并如实说明
- **不用别的模型批量生成样本**；每条增广要有 `light ai check` 真值背书
- 不提交 checkpoint 到 git（`checkpoints/` 已 gitignore）
- 不挑样例、不拿 val loss 虚低当结论（按文件切 val，不按行切）
- **不在训练期间同机跑 `scripts/bench.py`**（会抢 CPU 核使速度失真）
- 不改 bench 口径、不动 `docs/Demo开发计划.md`、不上 OpenI / V100
