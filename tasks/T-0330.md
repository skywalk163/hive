# 语料清洗与 4096 词表构建

## 背景

`lightprism` 现在只有 64K 预算的**设计**（`docs/词表预算.md`），没有可以直接训练的**实词表**。
Demo 计划（`docs/Demo开发计划.md` §3）决定 demo 用 **4096 词表**，理由是 64K 嵌入层
（`65536×192=12.6M`）比整个 demo 模型还大，且 3MB 语料填不满。

**这张卡是唯一必须最先完成的卡**：词表定死之前，模型尺寸、token 化、训练都无法开工。

## 语料现状（实测，2026-11-11）

- `light/` 仓 `.light` 文件：**514 个，3.13MB**，md5 去重后 **508 个**
- `light/stdlib/` 下 119 个模块
- 这是**全部**可用语料，不是抽样

## 要做的事

### 1. 语料清洗 → `data/corpus/`

- 扫描 `light/**/*.light`，按 **md5 去重**（508 个）
- **必须剔除**：
  - `tests/`、`tests/archive/`、`lighttests/`
  - `bootstrap/` 里的自举生成产物（先人工抽 5 个看是否是机器生成，把判断依据写进报告）
  - `testproj2/`、`_r159_scratch/`、`demo/` 等一次性目录
- 保留：`stdlib/`、`examples/`、`src/`、`docs/` 下的 `.light` 示例
- 输出：`data/corpus/<相对路径>.txt`，每个文件一行 JSON 索引到 `data/corpus/index.jsonl`
  （字段：`src_path` / `bytes` / `md5` / `kept` / `reason_if_dropped`）

### 2. 构建 4096 词表 → `data/vocab_4096.json`

按方案书 §3 的分层，**在 4096 总预算内**按下列顺序分配（这是建议值，可微调但要写理由）：

| 层 | 建议条数 | 说明 |
|---|---:|---|
| `l0` | 44 | 光明 L0 核心字，**一字一 token，硬约束** |
| `syntax` | 512 | 高频语法组合（`遍历`/`设`/`段`/`若…则…`…），从语料统计 |
| `stdlib` | 768 | 标准库模块名/函数名 |
| `ascii` | 2048 | ASCII 可打印字符 + 常见标识符片段 |
| `control` | 31 | 4 结构标记 + 19 决策 token + 8 验证码 |
| 余量 | 693 | 留白，不要硬凑满 |

**不要**把 4096 塞满。留 15% 余量给后续新增。

### 3. 必须复用的既有能力

```python
from lightprism.vocab import check_l0_atomicity   # L0 一字一 token 硬检查
from lightprism.tokens import TokenSpace, VALIDATION_CODES  # 控制 token 清单
```

控制 token 的 id **必须与 `TokenSpace` 完全一致**（19 个决策 + 8 个验证码），
不许自己造一套。

### 4. 词表校验入口

新增 `--check` 模式：给定 `data/vocab_4096.json`，校验

1. 总数 ≤ 4096；
2. 44 个 L0 字各占 1 个 token（`check_l0_atomicity` 通过）；
3. 控制 token 与 `TokenSpace` 逐条对齐（数量、文本）；
4. 无重复 token；
5. 报告 UNK 率：对 508 个语料文件做字符级统计，**UNK 率必须 < 1%**。

## 完成标准

- `data/vocab_4096.json` 存在且 `--check` 全绿
- `reports/词表报告.md` 含：各层条数、剔除文件清单与理由、UNK 率、L0 原子性结论
- `tests/test_demo_vocab.py` 至少覆盖：总数上限、L0 原子性、控制 token 对齐、UNK 率
- 不修改 `src/lightprism/tokens.py`（那是全项目共享的，动它要另开卡）

## 禁止

- 不要动 `vocab.py` 的 64K `DEFAULT_BUDGET`（那是 64K 路线的设计，不与 demo 冲突）
- 不要为了「看起来更完整」往词表里塞语料里没出现过的词
- 不要提交 `data/corpus/` 下的原始语料（体积大且版权归 light 仓），
  只提交 `index.jsonl` 与词表；语料放在 `.gitignore` 里
