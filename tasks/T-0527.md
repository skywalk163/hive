## 背景

`examples/test_会话持久化用户目录.light` 第 41 行把临时根写死：

```
设 临时根 为 路径连接("/tmp", "lh_migrate_test")
```

0.88（FreeBSD 15.1）上该目录 2026-11-26 已由**另一个用户** `skywalk` 创建，权限 `drwxr-xr-x (0755)`；门禁 runner 用户是 `workbuddy`，既不能写也不能删，于是用例在第一个 `创建目录` 就失败：

```
错误: 运行时错误
  创建目录失败 '/tmp/lh_migrate_test/data/sessions': [Errno 13] Permission denied
  （位置: stdlib/文件系统.light:68）
  异常链: 文件系统.light:68 → test_会话持久化用户目录.light:46 → test_会话持久化用户目录.light:66
```

## 实测证据（提交 `e940664`）

- 0.88 隔离直跑 `python3 运行.py examples/test_会话持久化用户目录.light` 3 轮：**3/3 rc=1**（不是偶发抖动）；
- 同轮 0.88 全量（4 并发，641 例）该条也在失败集合内（rc=1）；换成目录属主用户跑即绿；
- 台账对拍里它是「新增红」之一，但既不是平台能力差异（环境红台账 E-01/E-02/E-06 不含它），也不是 flaky（隔离并不恒绿），故未登记，见 `tests/ci_environment_reds.txt`「T-0524 全量对拍」节。

结论：缺陷是**用例写死全局临时路径**，与别的任务/其它用户残留撞车；不是业务逻辑 bug。

## 修法

- 把临时根改成**每轮唯一**：优先用仓内已有的跨平台临时目录能力（`stdlib` 里现成的临时目录/`tempfile` 等价），路径形如 `<系统临时目录>/lh_migrate_test_<pid或随机后缀>`；不要依赖 `/tmp` 在 Windows 上存在。
- 保持原有断言语义与清理逻辑不变；清理放 `尝试/捕获`（或 finally 等价），清理失败不得掩盖断言结果。
- 顺带自查本文件其它写死绝对路径（`/tmp`、`/home`、盘符），一并换成运行时探测；**只改这一个文件**，别的 examples 另开卡。

## 红线

- 不许 `skip` / 放宽断言 / 改 `paths` 之外的文件（尤其不许动 `tests/flaky_registry.txt` 或 `tests/ci_environment_reds.txt` 去豁免）。
- 不许为了让残留目录「能用」而在用例里 `改权限`/`删别人的目录`。
- 不许 `git reset --hard` / `push --force` / `--no-verify`。
