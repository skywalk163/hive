## 上游语义（两条）

**#12 插件更新方式**：`listBundles()` 不再返回 `updatable: boolean`，改返回可选 `update`：`listVersions` 能读到更新版本的 → `'registry'`；
从固定到完整提交的 Git spec 安装的 → `'git'`；`updateBundle` 无法替换的不含此字段。旧 `updatable: true` 对应 `'registry'`。
`ManagementError.code` 新增 `unexpected-package`：带 `expected` 的安装（`updateBundle` 总会传）在 spec 装成**别的包或别的版本**时以此码失败。
注意 `plugin_manager` 工具本身从不返回该字段，不受影响。

**#18 搜索计费**：`web-deepseek-api` 新增 `searchBilling`/`fetchBilling`（`auto` 默认 / `account` / `api-key`）。
`auto` 下：DeepSeek 模型路由行为不变；其他会话与会话外操作在**无密钥时改用已登录账号**；`account` 只用账号；`api-key` 只用密钥。
非空 `*BaseURL`/`*ApiKeyEnv` 仍优先。`auth` 改为 `{sources, missingCredentialMessage?}`：**每个来源自带地址，列表顺序取代「账号优先」的隐式规则**；
来源 `kind` 可为 `account`/`api-key`/`misconfigured`（只在轮到它时才失败）。凭据读取错误保留原始 `Error` 作 `cause`；
解析抛 `AbortError`（即使 signal 未取消）返回 `WEB_ABORTED` 而非 `WEB_PROVIDER_ERROR`。

## 语言坑（光明语言，2026-11 实测）

1. `导出 a b c` 行末不能加句号（报「无法识别的语法元素 '.'」）。
2. 字符串不解释 `\uXXXX`：写真实字符；串内引号写 `\"`。
3. 不支持匿名函数 `段落() 返回 x` → 用具名包装段落。
4. `设 f(x) 为 v` 非法；下标/成员赋值写 `表[位] 为 值`。
5. 变量名避开关键字尾巴（`合并为` / `等待` / `映射`）。
6. `写` 只吃字面量或已赋值变量。
7. 跨模块未捕获异常定位块会错位 → 断言用 `转字符串(异常值)` 比消息。
