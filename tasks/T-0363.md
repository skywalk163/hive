## 已知高概率需移植（供参考，仍需自行核实）

- `session-append-overloads`：`Session.append` 必须实现「单事件 + 数组」两种重载 → `src/会话.light`
- `attachment-error-codes`：`AttachmentError` 继承 `HarnessError`、失败记录附件码而非 UNKNOWN → `src/附件准入.light` / `src/错误增强.light`
- `forge-change-request-overview` / `forge-pinned-diff` / `forge-review-reads`：`ChangeRequestSnapshot` 新增必填概览字段、
  `ChangeRequestCheck.rerun`、`ForgeActionFailure.{unknown,stale}`、`threadsTruncated`、`diff(head)` → `src/变更请求.light`
- `web-search-billing`：按能力（search/fetch）分别选择计费账号或 API Key、有序凭据来源 → `src/网页搜索.light`
- `plugin-update-method`：`BundleInfo.updatable` → `BundleInfo.update`，`ManagementError` 新增 `unexpected-package` → `src/插件注册表.light`
- `runtime-context-reminders`：运行时上下文日志文本加提醒包装、清空标记记录空快照 → `src/会话日志增量.light` / `src/时间上下文.light`
- `terminal-backend-cleanup-error`：`TerminalBackendCleanupError` 改继承 `TerminalError` 且带 `CLEANUP_FAILED` → `src/终端.light`
- `subagent-interrupt-default`：内置配置把 `interrupt_agent` 默认关 → `src/子代理*.light` / `src/代理团队.light`

其余（`cua-*`、`window-drag-regions`、`terminal-bundle-sidebar-backend`、`account-*`、`archive-worktrees`、`dsh-doc-skill`）
大概率是宿主/UI/文档面 → §3 登记，但**必须读指南后再判**，不许照抄这句。
