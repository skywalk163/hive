# 新增 4 种 agent 模式（自上而下 / 自下而上 / 头脑风暴 / 懒人）— 预设数据层

## 背景

lightharness 已有 4 个 shipped 预设（standard / ptc / minimal / cordis），数据层在
`src/预设组合.light`，是上游 4 个 `*.patch.yml` 的逐行复刻：

- `规划组行`(41) / `压缩组行`(47) / `委派组行`(57) / `标准组合行表`(75) / `编码组合行表`(104)
  / `极简组合行表`(136) / `组装组合行表`(152)
- `组合清单`(182) 返回 `{standard:{order:1,…}, ptc:…, minimal:…, cordis:{order:4,…}}`
- `预设清单`(193) 返回**字面量** `["standard","ptc","minimal","cordis"]`
- `是已知预设`(196)

实测各预设挂的工具数：standard/ptc/cordis = 4（bash/读文件/写文件/搜索文件），minimal = 1（bash）。

目标：按 DSH 的模式规格，新增 4 个**组合型**模式，每个模式的差异只在
**控制流向 / 人机介入点 / 终止条件** 三个维度（规格见下），落成预设数据 + 文案。

## 四个模式的规格（照此实现，这是判据来源）

| id | 名称 | 工具集 | 系统提示注入 | 终止条件 |
|---|---|---|---|---|
| `topdown` | 自上而下 | 全 4 工具 + `目标`工具 | 先出计划树（节点/依赖/预估依据），计划是一等产物 | 计划树叶子全完成；或用户拒计划；或某节点失败无法回退 |
| `bottomup` | 自下而上 | 全 4 工具，**不给**目标工具 | 无中央规划器；领原子单元、独立执行；不主动请求确认 | 所有已发现单元处理完；或连续 N(>1) 轮无新有效输出；总轮次/成本上限 |
| `brainstorm` | 头脑风暴 | **只给只读工具**（读文件/搜索文件，**不给**写文件/bash） | 发散阶段禁评判；发散→收敛两阶段，中间有硬闸；收敛要有 Devil's Advocate + Steelman | 发散：到最大轮次或用户喊停；收敛：排序连续多轮稳定 |
| `lazy` | 懒人 | 全 4 工具 | 决策阶梯：不做 → 现成开源项目/服务 → 现成开源库 → 已有依赖/标准库 → 一行 → 写新代码；**进入代码层前必须留「方案层已穷尽」依据**；不追问细节、选默认值继续、末尾附默认决策日志 | 用户意图以最小必要产物被满足；或触发不可逆操作安全边界；或达硬迭代上限 |

**懒人模式的两个开关**（DSH 规格明确要求可调）：
`lazy.minimal_action`（最小必要行动）与 `lazy.no_ask`（最少交互自主跑），默认**都开**。
另加成本闸：**预估自写行数 < 20 行时不触发开源检索**（否则为了少写代码反而更慢）。

## 附注 A：「光明」写法禁令（照抄现状规避写法，成本最低）

- 段落一律块形式：**禁 `段落 X: 返回 …` 单行函数**（生成器缩进会累积）。
- 字典/列表字面量一律**单行**；嵌套字面量内不写 `\n`（用 `chr(10)`）；字面量不直接当实参先 `设` 变量。
- **单字变量名全禁**（`若 则 否 是 段 出 导 遍 对 跳 过 试 捕 抛 终 返 配 己 自 设 为 从 当 空 长 首 末 余 父 常 并 与 且 或 的 在 到 现 例 步 断 新 接 承 引 掷 跃 非 真`）。
- 标识符不得被关键字序列完全切分（`错误己` 会炸，`错误甲` 正常）；不用「为」字入标识符；
  避开含 `等待` 的标识符；成员名避开 `模/模型/模式/工具/事件/类型/原因/取/生成/新建` 等词根。
- 成员赋值一律 `设 己.X 为 …`（裸 `己.X 为 …` 会编成 `==`）。
- 缺键 `d[k]` 直接抛 `键错误` → 用 `字典获取(d, k, 缺省)` 或 `字典包含键` 守卫。
- `空` 是 `None` 不是 `""`，判空串写 `x != "" 且 x != 空`（照抄 `web服务器.light:452/522/527`）。
- `/` 是浮点除法，切片/下标前先 `整数()`。
- **段落名会与依赖模块内联后冲突**（`src/代理循环.light:10-12` 已记）：新模块段落统一加 2 字前缀
  （本批约定：`续`=目标续跑、`压`=压缩升级、`模`不许用→用 `式`、`队`=会话队列、`时`=会话细节）。
- 循环依赖用 `导入 模块` + `模块.段落()` 点号调用，不要 `从 X 导入 名`。
- 新模块名全仓唯一（`src/` 与 `stdlib/` 都要查）。
