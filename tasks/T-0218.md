## 背景

现在想看「在跑什么」，只有两条路：开浏览器看板，或者 `hive cluster status` 那一行
摘要。Windows 上还得先开个终端窗口（弹窗问题由 T-0206 负责，本卡不碰）。

`hive watch`（`hive_cluster.py::_watch`）已经有一条文本流，但它是「事件流水」，
不是「当前状态」，而且不会自己刷新布局。

## 要做什么

1. 新增 `hive_tui.py`（新文件，零第三方依赖）+ `hive.py` 里注册一个子命令
   （**只加 1 处 argparse + 1 处 dispatch，不动其他函数**）。
2. `hive top` 行为：
   - 默认每 2s 刷新一屏：头部（集群角色/term/在线节点/数据新鲜度）、
     中部（待领取 / 进行中 / 待合并 / 异常 四组的卡号 + 标题截断）、
     底部（时间 + `q` 退出提示）；
   - `--once` 打印**一帧**就退出（这是给测试用的稳定出口）；
   - `--width N` 固定宽度（默认取终端宽度，最小 60）；
   - 中文按**双宽**计算，超宽截断加 `…`；
   - 数据源：优先 `/api/status`（本机 8787），不可达回落本地 `hive status --json`
     的等价内存快照；两者都失败显示「无数据」而不是崩。
3. `q` / `Esc` / `Ctrl-C` 都能干净退出（恢复光标、清屏可选 `--no-clear`）。

## 不要做什么

- 不引入 `textual` / `rich` / `blessed`（CI 装包是新的不确定性；标准库够用）。
- 不做鼠标交互、不做编辑操作（只读视图）。
- 不碰 `hive_cluster.py` 的 `_watch`（另一条链路，别合并）。
- 不在 Windows 上额外开窗口（用当前终端）。

## 完成标准

- `python3 -m pytest -q tests/test_tui.py` 全绿（新文件）。
- 判据（都要有反证）：
  1. `--once --width 80` 输出每一行的**可见宽度 ≤ 80**（中文按 2 列）——
     去掉宽度裁剪必须红；
  2. `--once` 输出里四组标题齐全，且卡片数与输入快照一致（多一张/少一张都红）；
  3. 数据源不可达时输出「无数据」且退出码 0（不能抛栈）。
