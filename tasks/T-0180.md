## 背景

lightharness 的当前工作目录（cwd）决策目前是三套并行、互不引用：

1. **进程级全局**：`工具_路径安全.取根目录()` 用 `环境变量("HARNESS_ROOT", 当前目录())` 取根，`工具_bash` / `工具_写文件` / `工具_读文件` / `真实文件系统提供者` 跟随它判定越界。
2. **启动目录**：`cli外壳`（:114、:124）、`web服务器`（:230）、`mcp接线`（:70）、`总入口`（:449 等）各自调 `当前目录()`。
3. **会话头信息**：`会话.light:54` 构造时把 `工作目录` 写进 `"头信息"`，但**全仓没有任何模块读它做路径判定**——是死数据。子代理侧只有注释（`子代理深化.light:107`"子代理工作目录即其根"）没有实现，实际退回全局 HARNESS_ROOT。

后果：同一进程两个会话无法有不同目录；子代理切换 worktree 后分不清"谁的视图下写的文件"；`..` 越界判定按全局根而非会话根，会话根外、全局根内的目录会被放过。

## 目标

1. **新增 `src/工作目录.light`**（约 120 行），作为唯一入口导出三个函数：
   - `解析工作目录(候选, 兜底)`：候选为空或相对路径 → 按兜底解析（复用 `工作区路径.解析工作区路径`）；绝对路径 → 规范化后返回。
   - `断言可用(路径)`：运行时探测（存在、是目录、可读），返回 `{"ok":真}` 或 `{"ok":假,"理由":"..."}`，不抛裸异常。
   - `派生子目录(父cwd, 子候选)`：返回 `{"cwd":子生效目录, "originCwd":父源目录}`；子候选为空时回退 `{"cwd":父cwd, "originCwd":父cwd}`。
2. **会话头信息扩字段**（`会话.light:50-54`）：构造参数增加可选 `来源目录`；`头信息` 写入 `"工作目录"` 与 `"来源目录"` 两个字段；旧调用点（只传一个参数）自动回退 `来源目录 = 工作目录`。
3. **工具根改为"会话优先、环境兜底"**（`工具_路径安全.取根目录()`）：新签名接收会话 cwd 作为参数，优先用会话 cwd，`HARNESS_ROOT` 环境变量作为**强制覆盖**（优先级最高，保持 CLI headless 多会话共用一根的用法），最后才落到 `当前目录()`。
4. **收口各调用点**：`cli外壳` / `web服务器` / `mcp接线` / `总入口` 中自算 `当前目录()` 处改为从会话取（或经 `解析工作目录` 传入会话构造），总计约 6 处。
5. **新增 `tests/test_T0180_工作目录集中化.py`**，含下面"验收"中的 4 条用例，其中用例 1、2 是**反证用例**（假绿检测：如果实现未生效、路径判定仍走全局根，这两条必须红）。

## 红线

- ⛔ 不改现有路径安全规则本体：`..` 越界拒绝、前缀判定（POSIX `/` 与 Windows `\`）、软链归一化逻辑全部沿用 `工具_路径安全.解析安全路径` 现实现，只改"根从哪里来"。
- ⛔ 不废除 `HARNESS_ROOT`：保留为强制覆盖与 CLI 兜底。
- ⛔ 不做旧会话数据迁移：头信息没有 `"来源目录"` 的旧记录，读时回退为 `来源目录 = 工作目录`。
- ⛔ 不动 `子代理深化.light` / `子代理续传.light` 的委派逻辑（只允许把 cwd 传递改为调 `派生子目录`，如需要；不加新规则）。
- ⛔ 不碰工作区里其它人未提交的 reports/ 改动。

## 验收

`git show --stat HEAD` 应覆盖 `src/工作目录.light`（新增）、`src/会话.light`、`src/工具_路径安全.light`、`tests/test_T0180_工作目录集中化.py`（新增），及 ≤4 个调用点文件。

pytest 四条用例（summary 里逐条贴结果）：

1. **反证：会话根优先于全局根**。构造会话 A（cwd=临时目录 `/tmp/a`），工具 `解析安全路径` 读 `../b/x`（越出会话根、但在全局 HARNESS_ROOT 之内）→ 必须拒绝。若此条通过而实现仍走全局根，说明假绿，先修测试再谈通过。
2. **反证：同进程双会话各用各的根**。会话 A（cwd=dir_a）、会话 B（cwd=dir_b），各自读自己目录下文件 → 各自成功，互不影响；A 读 B 的文件 → 拒绝。
3. **派生字段分离**。`派生子目录(父cwd, 子候选)` 返回的 `cwd` 与 `originCwd` 值正确；子候选为空时两者相等回退。
4. **运行时断言**。会话创建后删除其目录，`断言可用` 返回 `{"ok":假,"理由":...}` 且不抛裸异常。

另外：全量回归 `python -m pytest -q tests/` 不得因本卡出现新的失败（既有 flaky 以 `flaky_registry.txt` 为准）。
