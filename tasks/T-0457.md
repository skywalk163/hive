# Python 惯性诊断 + 消灭 L0000 占位码

## 背景（实测，2026-11-24）

```
文件内容：def 问候():\n    print("hi")
light ai check --json →
  {"code": "L0000", "line": 1, "column": 9,
   "message": "无法识别的语法元素：':'。",
   "hint": "检查冒号「:」位置是否正确。",
   "fixes": ["检查冒号「:」位置是否正确。"], "candidates": [], "provisional": true}
```

真正错的是 `def`，报错指向冒号、fixes 是把 hint 抄了一遍、candidates 为空。**agent 会去修冒号，白烧 3–4 轮**。

根因：`src/diagnostics/registry.py` 的 19 条规则靠**自由文本正则**推断错误码，而这条报错的文本里根本没有 `def`，所以永远归因不上，CLI 落到 `L0000` 占位码（`cli/light.py:1762` 的注释自述了这件事）。

`docs/AI编程指南.md` §六 的「14 个高频错误」就是本卡的**需求清单**：那 14 条正是 agent 最高频的失败。

## 要做什么

1. 新模块 `src/ai_pyisms.py`（纯标准库，**不改 lexer/parser 行为**）：

   ```python
   @dataclass
   class Finding:
       line: int; column: int; end_column: int      # 1-based，字符列
       code: str                                     # D1xx
       wrong: str; right: str                        # 'def' → '段落'
       message: str                                  # 一句中文，说清"这行要改成什么"
       replacement: str                              # 整行级替换后的文本，可直接套 light patch

   def scan(source: str) -> list[Finding]: ...
   ```

   用 `src/lexer.py` 的公开分词接口取 token（token 自带 `行:列`，`python -m cli.light tokens x.light` 可验证），按 token 序列匹配，**不要用正则扫全文**（会和字符串/注释里的 `if` 打架）。

2. 必须覆盖 `docs/AI编程指南.md` §六 全部 14 条，至少这些映射：
   `def`/`function` → `段落`；`if` → `若`；`elif` → `否则若`；`else` → `否则`；`for` → `遍`；`while` → `当`；`return` → `返`；`True/False/None` → `真/假/空`；`and/or/not` → `且/或/非`；`&& || !` → `且 或 非`；`print(` → `打印(`；空列表/字典的 Python 写法 → `新建列表()`/`空字典()`（以指南原文为准）。

3. 每条 `replacement` 必须是**能直接替换的整行文本**，不是"请检查"。找不到安全替换时 `replacement` 留空串并在 `message` 里给出正确写法——**不许编一个错的替换**。

4. `src/diagnostics/registry.py` 新增 `D1xx` 段（`PY_DEF`/`PY_IF`/`PY_BOOL`/`PY_LOGIC`/`PY_PRINT`/`PY_COLLECTION` 等），并把 `explain()` 改为：命中 pyisms 时按真实 code 返回，`provisional=False`。

## 不要做什么

- 不改 `cli/light.py`（T-0464 收口卡接电，改它会冲突）
- 不改 `src/lexer.py` / `src/light_parser_v3.py` / `src/keywords.py`
- 不把 warning 升成 error；不造"兜底假码"
- 不新增依赖、不联网

- 断言 `explain()` 对 `def`/`if`/`&&`/`True` 返回非 `None`，`code` 以 `D1` 开头
- 一个"同时踩 5 种惯性"的样本，扫描结果 5 条、无一条 `L0000`
