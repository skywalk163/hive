## 背景
`profiles/` 四档全为 FreeBSD 语义（`jail: true`、ZFS dataset、pf 规则），`manuals/` 与 `checklists/` 只有 FreeBSD 版。Linux 用户（Ubuntu/Debian/Rocky）没有可用档位与部署手册。Go 内核本身跨平台，缺的是 profile 与运维文档。

## 目标
1) 新增 Linux profile（沿用现有 schema，不破坏旧 profile）：
   - `profiles/lims-linux-solo.profile.yaml`：SQLite、无 PG、无 jail，backend=sqlite，路径 `/opt/lightmem`。
   - `profiles/lims-linux-family.profile.yaml`：PG+pgvector、无 jail、无 ZFS（数据目录用普通 ext4/xfs 路径）、`jail: false`。
   - 必要时在 profile 增加 `platform: linux` 字段（若现有 schema 不接受未知字段，则只靠注释与 `jail:false` 表达，勿强改 schema）。
2) 新增 `manuals/linux-setup.md`：Ubuntu 24.04 / Debian 12 / Rocky 9 三平台：Go 1.25 安装、PG+pgvector 安装（apt/dnf）、non-root `lightmem` 用户、`/opt/lightmem` 目录、systemd 双服务、端口、防火墙（ufw/firewalld 放行 7443/7444）、排障（ss/systemd/journalctl）。
3) 新增 `checklists/linux-security-checklist.md`：对照 freebsd 版逐项给 Linux 对应（non-root、防火墙、token 文件 0600、TLS 反向代理建议、日志权限）。
4) `profiles/README.md` 增 Linux 档位说明与手册链接。

## 红线
- 不改现有四份 profile 的语义与字段（只增不改）。
- 不改 kernel profile 解析代码（若 schema 不支持 `platform` 字段就不加，写进 summary）。
- profile YAML 必须通过现有加载测试。

- 用新增 solo profile 起一次内核（`go run . -profile ...` 或二进制）冒烟 `/healthz` 返回 200，贴命令与输出。
