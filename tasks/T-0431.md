## 背景

`examples/test_agentE5钩子.light` 长期红，报：

```
错误: Exception
  通过: 注册默认钩子错误: 属性错误
  类 聊天v1 缺少方法/属性 调用（test_agentE5钩子:59）
  （Python 原始错误：'聊天v1' object has no attribute '调用'）
```

这是**测试桩没跟上被测 API 的演进**：用例里自己写的假客户端类 `聊天v1`
只实现了旧接口，而代理循环现在调的是 `调用`（或已改名的方法）。

## 期望修法

1. 先确认真实客户端接口现在叫什么：
   ```bash
   grep -n "段落 " src/客户端.light | head -20
   grep -rn "\.调用(\|\.对话响应(" src/代理.light | head
   ```
2. 让测试桩补齐新方法（**保持它是桩**：不引网络、不引真实密钥），
   行为与原 `对话响应` 一致即可。
3. 若该用例测的钩子行为已随 API 迁移到别处，则更新用例**测新位置**，
   并在文件头注释说明「为何迁移」，不要为了让它绿而删断言。

## 注意

- 别把桩改成「什么都返回空」——这个用例的价值在于验证 E5 钩子在真实一轮里
  被正确触发（注册 → 触发 → 收到事件），空实现会让它变成永远绿的空壳。
- 同目录若还有别的用例引用 `聊天v1`，一并检查。

## 判据

```bash
python 运行.py examples/test_agentE5钩子.light
```

反跑：把钩子注册那句注释掉，用例**应变红**（说明它真的在测钩子触发）。
