# 会话级模式与权限：切换会话恢复，审批按会话预设判定

## 背景

- **模式**：`webui/app.js:797` 每条消息带 `body.preset`，值来自 `mode-select`，
  记忆在 `localStorage`（`app.js:1125`）。服务端按 preset 选注册表
  （`src/web服务器.light:408-445`），但**会话本身不记录模式**——切回旧会话时
  下拉显示的是「上次全局选择」，用户看到的模式与实际跑过的模式可能不一致。
- **权限**：`权限管理器` 是进程级单例（`src/web服务器.light:103/125`、
  `src/权限.light:58`），`POST /api/permissions` 改的是全局面；`检查(工具名, 参数)`
  只读 `己.预设`（`src/权限.light:171-185`）。同一进程两个会话无法各用各的权限，
  A 会话切「全放行」会把 B 会话一起放开。
- 上游 DSH：模式与权限都随会话走，切换会话即恢复。

这卡把「模式/权限」从全局变量改成会话属性，并把审批判定切到会话预设。

## 要做什么

1. 会话索引元数据 + 头信息记录 `模式`、`权限预设`（可选键；缺省回退当前全局默认，
   旧数据不迁移）。
2. 每轮请求把**实际生效**的 preset / 权限预设写回会话记录；
   `GET /api/sessions/current` 与 `GET /api/sessions/:id` 返回这两个键（只增不改）。
3. 前端切换会话时恢复 `mode-select` 与 `perm-preset`（不再被 localStorage 单一值覆盖）；
   用户在某会话内切换后只影响该会话，刷新/切回仍能还原。
4. 权限按会话生效：`权限管理器.检查` 接受会话预设覆盖，或按会话构造独立的
   管理器/审批钩（`src/agent.light:149` 的 `注册默认钩子` 已支持按实例注入）。
   必须做到：同一进程内两个并发会话，一个「全放行」一个「全拒绝」时，工具检查结果
   各自正确、互不影响。`POST /api/permissions` 只改默认值，不改已绑定会话。
5. 新建会话（T-0396 面板）可指定模式/权限，创建时写入记录。
6. 新增 `tests/test_T0397_会话模式权限.py`：持久化/恢复；两会话并发权限隔离
   （同一工具在两个会话分别得到 放行/拒绝）；未设置时回退默认「标准 + 按类别」；
   `/api/permissions` 改默认不影响已绑定会话。

## 不要做什么（红线）

- 不改变默认行为：没有会话级设置时，仍是「standard + 按类别」。
- 不改审批队列的协议与事件形状（`审批请求`/`审批结果` 帧），不改 `examples/` 期望。
- 不动四预设语义与危险命令分类（`src/权限.light` 的分类逻辑）。
- 不把权限做成「切换会话时改全局管理器」——那等于没解决并发；必须隔离或显式传参。
