lightharness 依赖 light 与 lightplugin 并排（缺了会报 `No module named 生产挂载`，极具迷惑性）。

写一个 `scripts/fetch-deps.sh`：在空目录里克隆三个仓并平铺，跑完直接 `python 运行.py examples/冒烟.light` 有输出。同时把 README 的「一个容易踩的坑」一节改成先跑这个脚本。
