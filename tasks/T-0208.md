## 背景

Windows 上 hive 的常驻部分（看板服务 + 集群/worker）现在有三个缺口：

1. **没有日志文件**：输出跟着控制台走，窗口一关就没了；`dashboard-service.cmd`
   只在起停时打几行。
2. **没有单实例守护**：`dashboard-service.cmd start` 重复执行会撞端口；
   集群那边虽然有 pid 文件，但看板没有。
3. **没有常驻视图**：用户想「看一眼在跑什么」，只能开浏览器或翻终端。

弹窗的**根因不在这张卡**（在 T-0206 的子进程标志）。这张卡只解决「不打扰 +
随时可查」，把 TUI 留给后续可选卡。

## 要做什么

1. **日志轮转**：常驻进程输出落 `~/.hive/logs/hive-YYYYMMDD.log`，按天切分，
   保留 7 天（天数可配，默认 7），启动时清理超期文件。写入用追加 + 行缓冲，
   不引入第三方库。
2. **单实例守护**：启动前检查（a）pid 文件里的进程是否存活（Windows 用
   `tasklist /FI "PID eq N"`，POSIX 用 `os.kill(pid, 0)`）；（b）端口是否已被
   本程序占用。已在跑就**只打开看板 URL 并退出 0**，不再起第二个进程。
3. **系统托盘**：`windows/tray.ahk`（AutoHotkey v2），菜单项：状态 / 启动 /
   停止 / 打开看板 / 打开日志 / 退出；状态项显示「运行中 · 主节点 x · 在跑 N 张」，
   数据取 `/api/cluster/health` 与 `/api/status`（失败显示「未运行」不报错）。
4. 把 `scripts/install-autostart.ps1` 的计划任务指向「单实例启动入口」，
   重复登录不会起两个。

## 硬约束（本仓已踩过的坑，必须遵守）

- `windows/tray.ahk` 与 `scripts/*.ps1` **必须带 UTF-8 BOM**：PowerShell 5.1
  对无 BOM 文件按 cp936 解码，中文会破坏字符串终止，脚本连解析都过不去。
- 任何 `Stop-Process` **必须按 PID 或窗口标题过滤并先打印清单**，禁止
  `Get-Process xxx | Stop-Process -Force` 这种一把梭（2026-10-28 曾一次杀掉
  用户 10 个记事本窗口）。
- 托盘/日志路径不得写进仓库；`~/.hive/logs/` 已在 .gitignore 之外，注意别提交。

## 不要做什么

- 不做全屏 TUI（`hive top` 是后续卡）。
- 不引入 Python 第三方依赖（textual / rich 都不行）。
- 不改弹窗根因（T-0206）；本卡的「不打扰」指不额外制造窗口，不是消灭已有弹窗。
