## 背景：一个把主控骗了三回的显示 bug

2026-11-21 我（主控）连合 3 张卡（T-0429 / T-0430 / T-0431），每次都被同一个现象误导：
`hive task list` 里这几张卡**一直显示 `assigned` / `ready`**，看起来像「agent 推了分支但没提交」。
于是我每次都手工复核 + `close --as-done` 代劳，还在对话里三次断言「agent 没走 hive submit、
流程有缺口」——**这个结论是错的**。

真相：三张卡都正常 submit 过了。`hive result` 能看到完整的 done + agent + 耗时：

```
$ python3 hive.py result T-0429
T-0429  done  by doubao-win  (1242.2s)
branch: task/T-0429  head: 4a9c091...
```

## 根因（已定位到具体代码）

两条读取口径不一致：

| 命令 | 读什么 | 结果 |
|---|---|---|
| `hive status` | 先批量读 `origin/res/{tid}:results/{tid}.json`，再叠加卡面 | ✅ 正确显示 `done` |
| `hive task list` | 只读 `tasks/T-*.md` + store 租约 overlay（`Hive.cards()`） | ❌ 永远看不到 res 结果 |

- `hive.py:2740 cards()` → `sorted((dir/"tasks").glob("T-*.md"))` + `_overlay_store_state`
- `hive.py:2727 _overlay_store_state` → **仅在 store 里有未过期租约时才覆盖**（这条前提本身是对的，
  见 1314 行注释分析过的 2026-10-30 事故）
- `cmd_submit`（`hive.py:5280`）→ 只把结果推到 `res/T-xxxx` ref + store，**不重写卡面 `state:`**
- `cmd_status`（约 5859 起）→ 会 `read_ref_files_batch` 读 res 结果

于是：submit 完成后租约被释放 → overlay 失效 → 卡面 `state` 还是 `assigned` → `task list` 显示 assigned。
**卡面 state 是「派单时的状态」，不是「作业完成后的状态」**，而 task list 只看卡面。

## 期望修法（任选，倾向第一种）

1. **让 `task list` 叠加结果状态**：复用 `cmd_status` 已有的 `read_ref_files_batch` / `result_info`，
   对每张卡查一次结果；存在结果且 status=done → 显示 `done`，并回填 owner。
   注意别退回到「无条件用 store 覆盖卡面」的老坑（见 1314 行注释）。
2. **至少加一列**：`task list` 输出加 `result` 列（`done`/`failed`/空），让人一眼看出「已交但未关」。
3. 顺带：`cmd_submit` 成功后可选择**同时**把卡面 `state` 写成 `submitted`（不要直接写 done，
   done 归 land/close），让 git 卡面也能反映「已交付待合入」。

## 判据（必须可反跑）

```bash
# 1) 造一张卡：卡面 state=assigned，但有 res ref 结果（done）
#    task list 必须显示 done（或 result 列为 done），不能是 assigned
# 2) 反跑：把该 res ref 删掉 → task list 应回到 assigned
# 3) 回归：close/land 后卡面与显示仍一致；status 与 task list 口径不得再打架
python -m pytest tests/ -q -k "task and list"
```

**验收红线**：修完后，随便找一张已 submit 未 close 的卡，`hive task list` 与 `hive status`
的 state 列必须一致。建议把这条写成自动化判据（两命令输出对拍）。

## 为什么这张卡值得做

它不产生功能，但它**系统性地误导主控**：让主控以为 agent 没交货、于是手工代劳，
既费人力又把「自动 land + 结果留痕」整条链废掉。同类显示口径不一致以后还会犯，
建议顺手在 `docs/AGENT快速上手.md` 主控章节写一句：**判断「交没交」只看 `hive result` / `hive status`，
不要只看 `task list`**（在修好之前）。
