## 背景

母文档 v0.5 §4 要求控制面只安装 `(incarnation, version)` 严格变大的条目（I5），
并按 §4.3 实现 DNA 稳态抑制。共享骨架 `hive_control/model.py` 已落在 main
（`StateEntry` / 版本比较 / `IncarnationStore`），本卡只写视图与待下行队列。

先读 `docs/控制面v0.5-实现约定.md` §3.1 与 §4（D3/D6），接口以契约为准。

## 目标

实现 `hive_control/view.py`：

1. `InstallResult(installed: bool, reason: str)`，reason ∈ `new|newer|stale`。
2. `StateView.install()`：无条目→`new`；严格更大→`newer`；相等或更旧→`stale`。
   `stale` 不写日志、不抛异常、不回调。
3. `get / entries / watermarks / changed_after`：
   - `entries(project=None)` 按 `(project, tid)` 排序；
   - `watermarks(project)` 返回 `{tid: (incarnation, version)}`；
   - `changed_after(project, watermarks=None, floor=None)`：有逐条水位按逐条比；
     否则 `floor` 当全局下界；两者都没有返回全部，结果排序稳定。
4. `mark_quiet(interval, now=None)`：`state=="steady"` 且未 DNA、距上次变化
   ≥ `3*interval` 的条目置 `dna=True` 并返回；DNA 条目仍留在 `entries` /
   `changed_after` 里。任何成功安装都刷新该条目的“上次变化时间”，
   并把 dna 复位为条目自带值。
5. `DownlinkQueue`：`put` 同 key 只保留版本大者；`drop`；`drain` 清空并返回
   按 `(project, tid)` 排序的列表；`len`。
6. 所有公开方法线程安全（内部 RLock）；`install` 不做 I/O。

## 不要做什么

- 不改 `model.py / config.py / wire.py`，不引入第三方依赖。
- 不实现下行发送、网络、租约；不读写文件。
- `mark_quiet` 不要用真实 sleep 计时，`now` 可注入。
