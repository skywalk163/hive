## 背景

母文档 v0.5 §4 要求控制面只安装 `(incarnation, version)` 严格变大的条目（I5），
§4.3 要求 DNA 稳态抑制。共享骨架 `hive_control/model.py`（StateEntry / 版本比较 /
IncarnationStore）已落在 main；本卡只写视图与待下行队列，不改骨架。

落地契约见 `docs/控制面v0.5-实现约定.md` §3.1（view.py）与 §4 的 D3/D6。

## 目标

新增 `hive_control/view.py`，按契约实现：

- `InstallResult(installed, reason)`，reason 为 `new` / `newer` / `stale`；
- `StateView`：
  - `install(entry, now=None)` 严格按 I5，stale 不覆盖、不回调、不写日志；
  - `get` / `entries(project=None)`（按 `(project,tid)` 排序）；
  - `watermarks(project)` 返回 `{tid: [incarnation, version]}`；
  - `changed_after(project, watermarks=None, floor=None)`：逐条水位优先，缺水位时
    用 `floor` 当全局下界（D3）；
  - `mark_quiet(interval, now=None)`：`steady` 且连续 `dna_quiet_intervals`（=3）
    个下行周期无变化 → `dna=True` 并返回；DNA 不改进版本，仍留在 entries/拉取结果里；
  - `stats()` 提供条目数 / DNA 数 / 安装与 stale 计数；
  - 所有 `now` 可注入，默认 `time.monotonic`。
- `DownlinkQueue`：`put` 同 key 只留版本大者且不接收 DNA 条目，`drop` / `drain` /
  `__len__`；`drain` 按入队顺序返回并清空。

新增 `tests/test_control_view.py`，用注入时钟覆盖 I5、水位/增量、DNA 窗口与队列语义。

## 红线

- 只改 `hive_control/view.py` 与 `tests/test_control_view.py`；
- 不改 `model.py` / `config.py` / `wire.py` / `hive_control/__init__.py`；
- 不引入第三方依赖；不实现下行发送、网络、租约；不读写文件；
- `mark_quiet` 不得用真实 sleep 计时（now/clock 必须可注入）。
