## 要做什么

### 1. `hive prompt <T-xxxx>`

```text
hive prompt T-0184                       # 打印 markdown 指令
hive prompt T-0184 --agent trae-win      # 追加领取身份行
hive prompt T-0184 --format json         # 输出 payload 单行 JSON（脚本用）
hive prompt T-0184 --clip                # 打印并复制到剪贴板
hive prompt --task T-0184                # 与位置参数等价（兼容旧写法，二者取其一）
```

- 读卡用现有 `self.card(tid)`；body 从卡文件正文取（`parse_card` 已返回 body，**不要重新拼 frontmatter**）；
- 卡不存在 → `HiveError`（退出码 1，stderr 可读），**不要**打 traceback；
- `--clip`：`os.name == "nt"` 用 `clip`（复用现有 `worker` 里的写法与 `text=True`），
  其它平台依次尝试 `pbcopy` / `xclip -selection clipboard` / `wl-copy`，
  全部不可用或失败时**只打印警告**（stdout 正文照常输出），不改变退出码；
- `--format json` 时 stdout **只**有一个 JSON 对象（不加日志行），保证脚本 `json.loads` 能直接吃。

### 2. `hive dispatch-mark <T-xxxx> --agent <name>` / `--clear`

- `TASK_FIELDS` 末尾追加 `"dispatched_to", "dispatched_at"`（**追加到列表末尾**，不动已有顺序，
  避免所有旧卡被大面积重写）；
- 用 `dispatch_tracking.mark_dispatched` / `clear_dispatched` 生成新卡 dict，
  `state` 保持 `ready`（推送不等于分派：真正的分派仍是 `assign`）；
- 写回后 `commit_and_push(f"dispatch-mark {tid} -> {name}", [f"tasks/{tid}.md"])`，
  与 `assign`/`close` 的做法一致；推失败按现有 `commit_and_push` 的既有行为处理，不自己吞异常；
- `--clear` 与 `--agent` 互斥（同时给报错）。

### 3. `hive status` 显示 dispatched

- 用 `dispatch_tracking.summarize_board(cards)` 在表头上加一行分组摘要，
  例如 `待分配 4 / 已推送 2 / 在跑 1`，表体增加 `stage` 列（`pending` / `dispatched` / `claimed` …）；
- `--json` 输出里增加 `"stage"` 字段与 `"board"` 摘要块；
- **不得**改变既有列的含义与既有 `--json` 顶层键（只增不改）。

### 4. `dispatch` 的候选过滤

- `cmd_dispatch` 挑选候选时调用 `dispatch_tracking.is_dispatch_candidate`：
  TTL 内已推送的卡不再重复派（避免「重复通知同一个 agent」）；TTL 可读环境变量
  `HIVE_DISPATCH_TTL_MINUTES`，默认 60；
- 现有 `test_core.py` 的 dispatch 用例必须继续绿（旧卡没有 `dispatched_to`，行为不变）。

### 5. MCP 新工具 `hive_list_pending`

- `mcp_server.py` 注册 `hive_list_pending`，入参 `{"agent": <可选 agent 名>, "limit": <可选 int>}`；
- 不给 `agent` 时返回全部 `ready` 且无 owner 的卡（按任务号）；
  给了则用 `pending_matcher.match_tasks_for_agent(cards, agents[agent], limit=limit)`，
  agent 不存在时报错文本（不抛栈）；
- 返回结构与 `hive_list_tasks` 一致（`{"tasks": [...], "count": n}`），每条追加 `score` / `reasons`；
- 工具只读，不 claim。同步更新 MCP 工具清单类文档（README 或 docs/ 里现有的工具表，一处即可）。
